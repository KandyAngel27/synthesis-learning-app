# HITT 2335 / 2246 / 2149 / 2160 — Syllabus Coverage Audit

Audit of four Lone Star College HITT courses against their published Simple Syllabus
Course Overview and Student Learning Outcomes, checking that each Synthesis book
actually teaches what the syllabus claims the course covers.

**Method:** every objective was checked against **card body text**, not lesson titles.
Titles overstate coverage — a lesson can be named for a topic it barely teaches.

## A finding about the syllabi themselves

**The two Spring 2026 syllabi (2246, 2335) publish no Student Learning Outcomes
section at all.** Their Simple Syllabus pages contain Course Information, Instructor
Information, Course Overview, STAR Bundle, Required Texts, Technology Requirements,
dates, grading, policies and schedule — but no SLO block.

The two Summer 2026 syllabi (2160, 2149) do publish SLOs.

For 2246 and 2335 the audit therefore ran against the **Course Description** in the
Course Overview section, which is the only statement of course content those syllabi
publish. Both also point to D2L for the course schedule, so a fuller objective list
may exist there and is worth checking.

## HITT 2160 — Clinical: Health Information/Medical Technology

**Description.** *"A health-related work-based learning experience that enables the
student to apply specialized occupational theory, skills, and concepts. Direct
supervision is provided by the clinical professional."*

**SLO 1.** *"Apply the theory, concepts, and skills involving specialized materials,
tools, equipment, procedures, regulations, laws, and interactions within and among
political, economic, environmental, social, and legal systems associated with the
occupation and the business/industry."*

**SLO 2.** *"Demonstrate legal and ethical behavior, safety practices, interpersonal
and teamwork skills, and appropriate written and verbal communication skills using
the terminology of the occupation and the business/industry."*

**Verdict: fully covered.** This book reads as though it was written against this
syllabus. Every named element has substantial treatment:

| Element | Body-text hits | Lessons |
|---|---|---|
| political / economic / environmental / social | 12 / 13 / 11 / 17 | L16 is dedicated to exactly this |
| legal systems, regulations, laws | 8 / 39 | L6, L11, L15 |
| legal and ethical behavior | 27 | L6 (AHIMA Code of Ethics) |
| safety practices | 41 | L7 |
| interpersonal / teamwork | 8 | L17 |
| written and verbal communication | 38 | L17 |
| terminology of the occupation | 10 | throughout |
| supervision / preceptor | 54 | L1, L2 |
| professional practice experience | 55 | L1 |

Lesson 16 — *"HIM in Context: The Political, Economic, Environmental, Social & Legal
Systems"* — maps to SLO 1's unusual clause almost word for word.

## HITT 2335 — Coding & Reimbursement

**Description.** *"Development of advanced coding techniques with emphasis on case
studies, health records, and federal regulations regarding prospective payment
systems and methods of reimbursement."*

**Verdict: fully covered.** Every element is strongly represented:

| Element | Body-text hits |
|---|---|
| advanced coding techniques | 189 |
| case studies | 7 mentions plus a dedicated capstone lesson (L24) |
| health records / documentation | 132 |
| federal regulations | 69 |
| prospective payment systems | 155 |
| methods of reimbursement | 25 |
| Federal Register / final rule | 28 |

The book devotes ten lessons to payment systems specifically (IPPS/MS-DRG with
payment math, OPPS/APC, MPFS/RVU, SNF/HH/IRF/LTCH, ASC/hospice, managed care), which
is the heart of the description.

## HITT 2149 — RHIT Competency Review

**Description.** *"Review Health Information Technology (HIT) competencies, skills,
and knowledge."* — fully covered; 273 domain references across 28 lessons and 195
practice questions.

**SLO 1 — "Perform self-assessment of HIT competencies." COVERED.**
Lesson 1 has students rate themselves 1–5 on each of the five domains ("Be brutally
honest about where you are weakest"), works a full example of building a
domain-weighted study plan, and quizzes on study-time allocation. This is a genuine
self-assessment instrument, not a passing mention.

**SLO 2 — "Resolve learning gaps." WAS PARTIAL — now closed.**

The book had extensive *measurement* and no *method*:

| Probe | Hits before |
|---|---|
| "learning gap" / "knowledge gap" / "gap analysis" | **0** |
| "remediation" / "remediate" | **0** |
| "spaced repetition" / "review cycle" | **0** |
| "self-assessment" | 1 (Lesson 1) |
| "study plan" | 5 (all in Lesson 1) |

Strategy statements existed — *"Review every wrong answer. Focus on your weakest
domain"* — but there was no method for actually doing it. 195 practice questions
with no process for converting a wrong answer into closed knowledge.

**Added Lesson 29 — "Resolving Learning Gaps: From Wrong Answer to Mastery"**
(14 cards, 3 quiz): score-to-gap-inventory, the four causes of a miss
(knowledge / application / careless / timing) and why each needs a different fix,
the error log, retrieval + spacing + interleaving, test anxiety as a distinct
performance gap, proving closure (cold / delayed / novel / mixed), and writing
readiness criteria in advance.

The RHIT Final Exam simulation was also moved back to the end of the book, so the
remediation method is taught *before* the final simulation rather than after it.

## HITT 2246 — Advanced Medical Coding

**Description.** *"Advanced concepts of ICD and CPT coding rules, conventions, and
guidelines in complex case studies. Investigation of government regulations and
changes in health care reporting."*

**First sentence — fully covered.**

| Element | Hits |
|---|---|
| ICD-10-CM / PCS | 95 |
| CPT | 93 |
| official guidelines | 90 |
| conventions | 27 |
| Coding Clinic / CPT Assistant | 53 |
| complex case studies | 5 dedicated lessons (L8, L14, L19, L25, L26) |

**Second sentence — WAS THIN — now closed.**

| Probe | Hits before |
|---|---|
| government regulation / federal | **2**, both incidental (an appeals path, a HIPAA reference) |
| Federal Register / final rule / proposed rule | **0** |
| annual updates / code set changes | 2, incidental |
| IPPS + OPPS + rulemaking + transmittal + MLN combined | 7 |
| quality reporting changes | 3 |

The book taught how to *apply* rules thoroughly and barely touched **how the rules
themselves change** — which is a distinct clause of the course description.

**Added Lesson 27 — "Regulatory Change & Changes in Health Care Reporting"**
(14 cards, 3 quiz): the annual code cycle and date-of-service coding, Federal
Register rulemaking from proposed rule through comment to final rule, official
guidance and superseded advice, CMS transmittals/manuals/MLN Matters, NCD vs LCD
coverage policy, whole code set transitions (ICD-9→10 as the case study, ICD-11
status), OIG Work Plan and audit contractors, and changes in health care reporting
(IQR/OQR, HAC and POA, HRRP, VBP, HCC risk adjustment, price transparency, SDOH).

## Verification

- Both new lessons: 14 cards, 3 quiz cards, full-canvas SVG on every card, matching
  each book's local conventions (2246 uses string ids and `"N min"` durations;
  2149 uses numeric ids and numeric durations)
- Verified in a browser after a cache-busted reload: all four books load, no
  duplicate book entries, 0 cards missing a visual, and the app's own
  `ExamCenter.harvestLessonQuestions()` returns 96 / 198 / 75 / 53 questions
- Rest of the library unaffected: 314 books / 33 categories intact

## Caveat

Quantitative figures in the new lesson text (transition-era code counts, productivity
effects) are **illustrative and hedged**, not sourced citations. Verify against the
primary source before quoting to an instructor.
