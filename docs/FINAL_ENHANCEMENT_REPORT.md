## CONTENT STRATEGY FOR EACH LESSON

For optimal learning progression, add cards in this order:

### After Existing Content:
1. **FACT Card**
   - Interesting research finding
   - Adds credibility and "wow" factor
   - Full SVG with data visualization

2. **QUOTE Card**
   - Kahneman wisdom
   - Provides philosophical anchor
   - Elegant quote-style SVG

3. **EXAMPLE Card**
   - Real-world application
   - Makes concept relatable
   - Scenario-based SVG

4. **QUIZ Card**
   - Second quiz (tests deeper understanding)
   - 4 options with detailed explanation
   - Educational SVG with visual answer

5. **CONCEPT/APPLICATION Card**
   - Practical strategies wrap-up
   - "How to use this" guidance
   - Strategic action SVG

### Why This Order?
- Spaces out quizzes (not clustered at end)
- Builds from knowledge → application
- Maintains engagement through variety
- Ends with actionable takeaways
