### Unit 1: Windows 11 Mastery (L1-5)
1. **"The Windows 11 Desktop & Interface"** — What is an operating system (review from Technology in Action): software that manages hardware, runs applications, provides user interface. Windows 11: Microsoft's current desktop OS, released October 2021, centered Start menu, rounded corners, Snap Layouts, Widgets, Microsoft Teams integration, Android app support, system requirements (TPM 2.0, Secure Boot, 4GB RAM, 64GB storage, 1GHz 2-core 64-bit). The Desktop: wallpaper (personalize: right-click → Personalize, or Settings → Personalization), Taskbar (centered by default — pinned apps, Start button, Search, Task View, Widgets, system tray with clock/network/volume/notifications/hidden icons), Start menu (pinned apps section, recommended/recent section, power button, user account, search bar — searchable: apps, files, settings, web), desktop icons (Recycle Bin, optionally: This PC, User's Files, Network, Control Panel — enable via Settings → Personalization → Themes → Desktop icon settings). Taskbar customization: right-click Taskbar → Taskbar settings — show/hide Search, Task View, Widgets, Chat; pin/unpin apps (right-click app → Pin to taskbar); notification area (choose which icons appear), Taskbar alignment (center or left), auto-hide Taskbar. Quick Settings: click system tray area (Wi-Fi/Volume/Battery cluster) — Wi-Fi, Bluetooth, Airplane mode, Focus Assist, Accessibility, brightness slider, volume slider, battery information. Notifications: click date/time → Notification Center + Calendar — app notifications, quick dismiss, manage per-app notification settings. Lock screen: Windows+L — lock computer (require password/PIN to unlock, CRITICAL in healthcare — walk away = lock screen, HIPAA requirement). Sign-in options: Settings → Accounts → Sign-in options — password, PIN (Windows Hello PIN — TPM-stored, device-specific, faster than password), facial recognition (Windows Hello — infrared camera), fingerprint (Windows Hello), security key (FIDO2). Healthcare context: hospital workstation with Windows 11, shared workstations (fast user switching, each user signs in with own credentials), automatic screen lock policy (Group Policy — IT department sets 5-15 minute timeout), HIPAA physical safeguard compliance
   - Cover: Windows 11 desktop anatomy diagram (taskbar/Start/system tray/desktop labeled), Start menu layout, Quick Settings panel, sign-in options comparison

2. **"Window Management & Multitasking"** — Window controls: minimize (dash — to taskbar), maximize/restore (square — toggle full screen / windowed), close (X — closes app). Moving/resizing: drag title bar to move, drag edges/corners to resize. Snap Layouts: hover over maximize button → choose layout (2-up 50/50, 2-up 70/30, 3-up, 4-quadrant — arrange windows precisely). Snap Groups: snapped windows remembered as a group — hover over taskbar app to see group thumbnail, click to restore entire arrangement. Snap with keyboard: Win+Left/Right (snap to half), Win+Up (maximize), Win+Down (restore/minimize), drag window to screen edge (auto-snap). Multiple desktops (Virtual Desktops): Task View (Win+Tab) → New Desktop — create separate desktop workspaces (Desktop 1: Email + Calendar, Desktop 2: EHR + coding software, Desktop 3: reports + analytics). Switch desktops: Win+Ctrl+Left/Right arrows, or Task View → click desktop. Rename and reorder: right-click desktop in Task View. Alt+Tab: switch between open windows (hold Alt, tap Tab to cycle, release to select). Task View: Win+Tab — see all open windows across all desktops, timeline of recent activities. Task Manager: Ctrl+Shift+Esc — monitor running processes (CPU, memory, disk, network usage per app), end unresponsive programs (select → End Task), Startup tab (enable/disable startup programs — improve boot time), Performance tab (real-time CPU/RAM/Disk/Network/GPU graphs), App History, Services. Clipboard History: Win+V — view clipboard history (last 25 copied items), pin frequently used items, sync across devices (Settings → System → Clipboard → Clipboard history ON). Focus Assist: Settings → System → Focus Assist — suppress notifications during presentations, alarms only, priority only, or off. Accessibility: Settings → Accessibility — Narrator (screen reader), Magnifier (Win++ to zoom), High Contrast themes, Closed Captions, Mouse pointer size/color, text size scaling. Healthcare multitasking: EHR on main display + reference materials on second monitor, snap coding software alongside code books, virtual desktops for different workflows (clinical review vs administrative tasks), Task Manager to troubleshoot frozen EHR applications
   - Cover: Snap Layouts options grid, virtual desktop concept diagram, Alt+Tab vs Task View comparison, Task Manager tabs overview

3. **"Settings, Personalization & System Configuration"** — Settings app: Win+I — organized categories: System, Bluetooth & devices, Network & internet, Personalization, Apps, Accounts, Time & language, Gaming, Accessibility, Privacy & security, Windows Update. Settings vs Control Panel: Settings is the modern interface (most common settings), Control Panel is legacy (still accessible for advanced/legacy settings — appwiz.cpl for programs, ncpa.cpl for network, services.msc for services). System settings: Display (resolution, scaling — 100/125/150/175/200%, multiple displays — extend/duplicate/second screen only, HDR, night light — reduce blue light), Sound (output/input devices, volume mixer — per-app volume), Notifications, Focus Assist, Power (sleep timer, screen timeout, power mode — best performance/balanced/best efficiency, battery settings for laptops), Storage (see what's using disk space, Storage Sense — auto-clean temp files, cleanup recommendations), Multitasking (Snap settings, virtual desktop settings). Personalization: Background (picture, solid color, slideshow), Colors (light/dark/custom mode, accent color — auto from wallpaper or manual, transparency effects, title bar/taskbar accent), Lock screen (background, status apps, screen timeout), Themes (saved combinations of background + color + sounds + cursor, download from Microsoft Store), Taskbar, Start, Fonts. Apps: Installed apps (uninstall, modify, repair), Default apps (set default browser, email client, music player, photo viewer, video player, PDF reader), Startup apps (toggle on/off), Optional features (add/remove Windows features). Accounts: Your info (name, picture, Microsoft account vs local account), Email & accounts, Sign-in options, Family & other users, Windows backup (OneDrive settings). Privacy & security: Windows Security (virus protection, firewall, device security), Find my device, Device encryption (BitLocker on Pro/Enterprise), app permissions (camera, microphone, location, contacts — review and restrict per app). Windows Update: Settings → Windows Update — check for updates, update history, pause updates (up to 5 weeks), active hours (prevent restarts during work), optional updates (drivers, feature updates). Healthcare configuration: IT-managed settings (Group Policy restricts many settings on hospital workstations — users can't change security settings, install unauthorized software, or disable encryption), approved software installation procedures, automatic updates managed by WSUS/SCCM/Intune, screen lock timeout mandatory for HIPAA
   - Cover: Settings app category overview, display scaling comparison, personalization options, privacy & security settings checklist

4. **"File Explorer & File Management"** — File Explorer: Win+E — THE file management tool. Interface: Navigation pane (left — Quick Access/pinned folders, OneDrive, This PC, Network), Address bar (shows current location — click to type path directly, breadcrumb navigation — click any folder in path to jump), Search bar (top right — search within current folder and subfolders), Ribbon/Command bar (new in Win 11 — New, Cut, Copy, Paste, Rename, Share, Delete, Sort, View, more via ⋯), Details pane (optional — shows file properties without opening). File system hierarchy: drives (C: = system drive, D: = data/secondary, network drives mapped as letters) → folders → subfolders → files. This PC: shows all drives (Local Disk C:, USB drives, network drives), and User folders (Desktop, Documents, Downloads, Music, Pictures, Videos). File paths: C:\Users\kandy\Documents\Reports\Q1_Report.xlsx — drive:\folder\subfolder\filename.extension. File extensions: .docx (Word), .xlsx (Excel), .pptx (PowerPoint), .pdf (Acrobat), .txt (plain text), .csv (comma-separated), .jpg/.png/.gif (images), .mp4/.avi (video), .mp3/.wav (audio), .zip (compressed), .exe (executable program). Show extensions: View → Show → File name extensions (ALWAYS enable — know what you're opening, security awareness — "invoice.pdf.exe" is malware disguised). Creating: right-click → New → Folder/Document type, or New button in command bar. Selecting: click (one), Ctrl+click (add to selection), Shift+click (range), Ctrl+A (all). Operations: Copy (Ctrl+C), Cut (Ctrl+X), Paste (Ctrl+V), Rename (F2 — select file → F2 → type new name), Delete (Delete key → Recycle Bin, Shift+Delete → permanent), drag-and-drop (same drive = move, different drive = copy, Ctrl+drag = always copy, Shift+drag = always move). Properties: right-click → Properties — General (type, location, size, created/modified/accessed dates), Security (permissions — who can read/write/execute), Details (metadata — author, tags, dimensions for images). File views: Extra Large/Large/Medium/Small Icons, List, Details (name, date modified, type, size — sortable by clicking column headers), Tiles, Content. Quick Access: pinned frequently used folders, recent files — right-click folder → Pin to Quick Access. Search: type in search bar — filters: kind:document, datemodified:this week, size:large, type:.xlsx. Healthcare file management: organized folder structure for department (\\server\HIM\Policies\, \\server\HIM\Reports\Monthly\2026\), naming conventions (YYYY-MM-DD_DocumentName_v1.0.docx), network drive mapping for shared resources, HIPAA — never save PHI to personal devices or unauthorized locations
   - Cover: File Explorer interface anatomy, file system hierarchy tree, file operations reference card, healthcare folder structure example

5. **"Search, Cortana & Productivity Features"** — Windows Search: click Search icon on Taskbar or press Win key and start typing — searches apps, files, settings, web results simultaneously. Search filters: Apps, Documents, Web, More (email, folders, music, people, photos, settings, videos). Search indexing: Settings → Privacy & security → Searching Windows — Classic (only Documents, Pictures, Desktop, and indexed locations) vs Enhanced (search entire PC — slower indexing, more comprehensive). File search in Explorer: type in search bar — Boolean operators (AND, OR, NOT), filters (kind:, datemodified:, size:, type:, name:, author:), save search as virtual folder. Clipboard history: Win+V — multi-item clipboard, pin items, clear history, sync across devices. Screenshot tools: Win+Shift+S (Snipping Tool — rectangular, freeform, window, or full screen snip → copies to clipboard, opens in Snipping Tool editor for markup/annotation/save), Print Screen (captures entire screen to clipboard), Alt+Print Screen (captures active window only), Win+Print Screen (saves screenshot directly to Pictures\Screenshots folder). Snipping Tool features: delay timer (3, 5, 10 seconds — capture menus/tooltips), annotation (pen, highlighter, eraser, ruler/protractor, crop, text), save as (.png, .jpg, .gif). Screen recording: Snipping Tool → Video mode (Win 11), or Xbox Game Bar (Win+G — screen recording, not just games). Voice typing: Win+H — dictate text in any text field, punctuation commands ("period", "comma", "new line", "question mark"). Widgets: Win+W — personalized feed (weather, news, calendar, stocks, sports, traffic, tips, photos), customize which widgets appear. Power Toys (optional Microsoft utility): FancyPaste (paste as plain text), Color Picker (identify any color on screen), PowerRename (bulk rename files with regex), File Locksmith (find which process is using a file), Text Extractor (OCR — extract text from images). Tips app: pre-installed Windows tips and tutorials. Healthcare productivity: screenshots for IT support tickets (capture error messages from EHR), clipboard history for copying multiple patient data fields (de-identified), voice typing for notes/documentation, search for policies/procedures across network drives
   - Cover: Windows Search filter options, Snipping Tool modes and markup tools, clipboard history concept, screenshot method comparison (Win+Shift+S vs PrtScn vs Win+PrtScn)

### Unit 2: Cloud Storage & OneDrive (L6-8)
6. **"OneDrive: Setup, Sync & Storage"** — What is OneDrive: Microsoft's cloud storage service, included with Microsoft 365 (1TB per user with M365 subscription, 5GB free with Microsoft account). OneDrive vs local storage: files stored in cloud AND synced to local computer — available everywhere (web, desktop, mobile), protected from local hardware failure, shared easily. Setup: sign in with Microsoft account or work/school account (auto-configured in enterprise via IT), OneDrive folder appears in File Explorer (C:\Users\[name]\OneDrive or OneDrive - [Organization Name]). Sync icons: blue cloud (online-only — not on this device, downloads on demand), green checkmark on white circle (available on device — cached, may be freed by Storage Sense), solid green circle with white checkmark (always keep on this device — pinned for offline access), sync arrows (currently syncing). Files On-Demand: Settings → Storage (OneDrive settings) — download files only when you open them (saves local disk space), right-click → Always keep on this device (pin for offline access — for files you need without internet: presentations, reference documents, traveling). Storage management: OneDrive → Settings → Account → Manage Storage — view used/available space, see largest files, empty Recycle Bin (deleted OneDrive files go to OneDrive Recycle Bin — recoverable for 30 days, then 93 days in second-stage). Folder backup: OneDrive → Settings → Sync and backup → Manage backup — auto-backup Desktop, Documents, and Pictures folders to OneDrive (redirects these folders to OneDrive). OneDrive web interface: onedrive.com — access files from any browser, upload, download, share, create new Office documents directly in browser, photo gallery features. OneDrive mobile app: iOS and Android — access files, upload photos automatically (camera upload), scan documents with phone camera to PDF, offline access for selected files. Personal Vault: extra-secure folder within OneDrive — requires additional authentication (PIN, fingerprint, face), auto-locks after inactivity, for sensitive documents (tax returns, ID scans, insurance cards). Healthcare OneDrive: work/school OneDrive managed by IT (policies on sharing, retention, DLP — Data Loss Prevention), HIPAA considerations (Microsoft 365 covered under BAA, but users must follow policies — no sharing PHI via personal OneDrive, organizational policies restrict external sharing), backup important work files, access documents from any hospital workstation
   - Cover: OneDrive sync icon guide, Files On-Demand concept, folder backup setup, Personal Vault security layers

7. **"OneDrive: Sharing, Collaboration & Version History"** — Sharing from OneDrive: right-click file → Share, or select → Share button. Share link types: Anyone with the link (most permissive — no sign-in required, public link), People in [Organization] with the link (anyone in your company — internal only), People with existing access (only people already shared with — for resharing), Specific people (named individuals — email required). Permissions: Can Edit (full editing rights), Can View (read-only), set expiration date (link expires after specified date), set password (require password to access), block download (view-only, prevent downloading — for sensitive documents). Copy link: generates shareable URL, paste anywhere (email, chat, document). Email invitation: enter email → recipient gets notification with link, optional message. Managing shared files: OneDrive web → Shared → Shared by me / Shared with me, manage access (change permissions, remove access, see who has access), stop sharing. Co-authoring: when two or more people have edit access to a shared Office document — simultaneous editing in Word/Excel/PowerPoint (desktop or web apps), see other editors' cursors/selections, changes sync automatically, requires AutoSave (cloud save). Version History: right-click file → Version History — see all saved versions with timestamps, open previous version, restore previous version (creates new version from old), download previous version. Recycle Bin: OneDrive.com → Recycle Bin — deleted files recoverable for 93 days (30 days first-stage + 63 days second-stage), restore to original location, permanently delete. OneDrive for Business vs Personal: Business (managed by IT, organization's SharePoint backend, compliance policies, DLP, retention, eDiscovery, admin controls), Personal (individual Microsoft account, consumer features, less administration). Healthcare sharing: share quality reports with committee members (view-only for non-editors), collaborate on policy documents (specific people, edit access), share training materials with department (organization link, view-only), NEVER share PHI-containing files externally without proper authorization, DLP policies may automatically block sharing of files containing SSN/MRN patterns
   - Cover: Share link permission levels comparison, co-authoring workflow, version history timeline, sharing best practices for healthcare

8. **"Cloud Storage Ecosystem: OneDrive, SharePoint & Teams Files"** — OneDrive vs SharePoint vs Teams files: OneDrive = personal cloud storage (your files, you control sharing), SharePoint = team/department shared storage (document libraries, managed by team/IT, structured collaboration), Teams Files = SharePoint underneath (each Teams channel has a SharePoint folder, Files tab = SharePoint document library). When to use each: OneDrive for personal work-in-progress (drafts, personal references, individual projects), SharePoint for department-owned documents (policies, procedures, templates, shared resources — outlive individual employees), Teams for project collaboration (active team projects, meeting files, channel-specific resources). SharePoint basics: sites (team sites, communication sites), document libraries (organized file storage with metadata columns, versioning, check-in/check-out, content approval, custom views), lists (structured data — like lightweight databases: issue tracking, project tasks, inventory). Accessing SharePoint: browser (sharepoint.com/sites/[sitename]), synced to File Explorer via OneDrive sync client (Sync button in SharePoint → appears as folder in Explorer), Teams Files tab. Syncing SharePoint to Explorer: open SharePoint library → Sync button → OneDrive sync client adds library to File Explorer — work with files locally, changes sync to cloud. Teams Files: each Channel → Files tab — upload, create new, edit, co-author, share. Files uploaded in Teams chat → stored in sender's OneDrive. Files uploaded to channel → stored in channel's SharePoint folder. Microsoft 365 integration: open any cloud-stored Office file in desktop app or web app, AutoSave for cloud files, recent files across all M365 apps, search across OneDrive + SharePoint + Teams from Microsoft Search bar. Storage and sync best practices: consistent folder structure, descriptive file names, don't nest too many subfolder levels (max 3-4), avoid special characters in file names (# % & { } \ < > * ? / ! ' " : @ + ` | =), keep file paths under 400 characters (OneDrive limit), use metadata/tags in SharePoint instead of deep folder hierarchies. Healthcare cloud ecosystem: HIM department SharePoint site (policy library with version control + approval workflow, coding references, meeting minutes archive), Teams for project collaboration (ICD-10 transition team, CDI initiative, EHR upgrade project), OneDrive for individual work (personal coding reference notes, draft reports, study materials), IT-managed policies control what can be stored where (PHI restricted to approved SharePoint sites, not personal OneDrive)
   - Cover: OneDrive vs SharePoint vs Teams Files comparison, SharePoint sync to Explorer workflow, Teams file storage architecture, healthcare cloud storage decision tree

### Unit 3: Microsoft 365 Core Apps (L9-13)
9. **"Outlook: Email Essentials"** — Outlook: email + calendar + contacts + tasks — the communication hub of M365. Outlook interface: Navigation pane (Mail, Calendar, People, Tasks, Notes — bottom-left icons), Folder pane (Inbox, Sent Items, Drafts, Deleted Items, custom folders), Message list (sorted by date, grouped by conversation or individually), Reading pane (preview message without opening — right or bottom, can be off). Composing email: Home → New Email (Ctrl+N) — To (required), Cc (carbon copy — visible to all recipients), Bcc (blind carbon copy — hidden from other recipients, use for mass emails to protect privacy), Subject (clear, descriptive — "Q1 Quality Report — Action Required" not "FYI"), Message body (formatting: Home tab in compose window — font, size, color, bullets, numbering, styles), Signature (File → Options → Mail → Signatures — auto-appended, different for new messages vs replies, multiple signatures for different contexts). Attachments: Insert → Attach File — attach from recent items, browse computer, or cloud locations (OneDrive/SharePoint — sends link instead of copy, enables co-authoring, always up to date, doesn't bloat inbox). Receiving: read in Reading pane or double-click to open, Reply (Ctrl+R — to sender only), Reply All (Ctrl+Shift+R — to all recipients, use judiciously), Forward (Ctrl+F — to new recipients). Organizing: folders (right-click Inbox → New Folder — organize by project, department, topic), move messages (drag or right-click → Move → choose folder), rules (Home → Rules → Manage Rules — auto-process incoming mail: from specific sender → move to folder, subject contains keyword → categorize/flag, sent to distribution list → move to folder), categories (color tags — right-click → Categorize — Red/Blue/Green/Yellow/Orange/Purple, rename for meaning: "Urgent", "Follow-up", "FYI", "Coding", "Quality"), flags (right-click → Follow Up — Today, Tomorrow, This Week, custom date — appears in To-Do), search (Ctrl+E — from:, to:, subject:, hasattachment:true, received:this week). Conversation view: View → Show as Conversations — groups related messages together (all replies in one thread), expand/collapse, ignore conversation (mute noisy threads). Email etiquette: professional tone, proofread before sending, appropriate use of Reply All (don't reply all for "thanks!"), use Bcc for large recipient lists, descriptive subjects, don't email sensitive/PHI information unencrypted. Healthcare email: encrypted email for PHI (Outlook M365 encryption: Options → Encrypt — Do Not Forward, Encrypt-Only, sensitivity labels configured by IT), distribution lists for committees and departments, auto-replies for out-of-office, HIPAA minimum necessary in email communication
   - Cover: Outlook interface anatomy, email compose elements, folder/rules/categories organization, email encryption options for PHI

10. **"Outlook: Calendar, Contacts & Tasks"** — Calendar: click Calendar icon in navigation. Views: Day, Work Week (Mon-Fri), Week (Sun-Sat), Month, Schedule View (side-by-side calendars for scheduling). Creating events: click-drag on time slot or Home → New Meeting/Appointment. Appointment vs Meeting: appointment = no attendees (block time for yourself), meeting = invite attendees (sends meeting request). Meeting request: required attendees, optional attendees, date/time, duration, location (physical room or online meeting), body (agenda, preparation notes), Scheduling Assistant (shows attendee availability — free/busy/tentative/out of office, find time when all are available), Room Finder (if rooms configured by IT — book conference rooms). Recurring events: set pattern (daily, weekly, monthly, yearly — every Monday, first Tuesday of month, etc.), end date or number of occurrences. Online meetings: Teams meeting (toggle "Teams Meeting" when creating — auto-adds join link, or always by policy), Outlook web → Zoom/Webex plugins (if configured). Responding to meeting requests: Accept (added to calendar), Tentative (added with ? marking), Decline (removed, optional response), Propose New Time (suggest alternative). Calendar management: overlay multiple calendars (personal + shared department calendar + holiday calendar), color-code categories, share calendar (right-click calendar → Sharing Permissions → share with specific people, set permission: Can view when I'm busy, Can view titles and locations, Can view all details, Can edit), publish calendar. Contacts (People): click People icon — create contacts (name, email, phone, company, address, job title, notes), contact groups/distribution lists (Home → New Contact Group — add members, send email to group name → reaches all members), import/export contacts (CSV). Tasks (To Do): click Tasks icon or use Microsoft To Do app — create tasks with due dates, reminders, priority, notes, recurring tasks, flag emails as tasks (appears in To Do), My Day (daily planning view), shared task lists. Healthcare calendar: committee meeting scheduling (use Scheduling Assistant to find common availability across 15 department heads), recurring quality committee (monthly, first Wednesday, 2-4 PM), room booking for training sessions, block coding time (appointment — "Coding Focus" 9-11 AM daily), shared HIM department calendar (team coverage, vacations, training), contact groups for: coding team, CDI team, medical staff office, quality committee members
    - Cover: Calendar views comparison, meeting request with Scheduling Assistant, recurring event patterns, task integration (flagged email → To Do)

11. **"Microsoft Teams: Communication & Collaboration Hub"** — What is Teams: unified communication and collaboration platform — chat, video meetings, file sharing, app integration, all in one place. Teams structure: Organizations → Teams → Channels. Teams: groups of people (HIM Department, Quality Committee, EHR Upgrade Project), Channels: topic-based conversations within a team (General, Policies, Coding Questions, Training, Social). Channel types: Standard (visible to all team members), Private (visible only to specific members — sensitive discussions), Shared (cross-team — members from different teams/organizations). Chat: one-on-one or group messages, rich text (formatting, tables, lists), @mention (notify specific person or channel), priority notifications (urgent — repeated notification every 2 minutes for 20 minutes), giphy/stickers (informal communication). Meetings: schedule from Teams or Outlook (synced), join meeting (video + audio + screen share + chat), meeting features (raise hand, reactions, together mode, breakout rooms, recording, transcription, live captions, whiteboard, polls), meeting notes (collaborative meeting notes — OneNote or Loop). Screen sharing: Share button → entire screen, specific window, PowerPoint (PowerPoint Live — attendees browse independently), whiteboard. Teams Files: each channel has a Files tab (SharePoint backend), upload/create/edit Office documents, pin important files to top. Apps and Tabs: add apps to channels — tabs at top (OneNote, Planner, SharePoint page, website, Excel workbook, Power BI report), connectors (RSS feeds, external service notifications). Teams phone: make/receive phone calls (if configured by IT — Teams phone system replaces desk phones in many organizations), voicemail, call forwarding, call queues. Notifications: manage per-channel (all activity, mentions only, off), @team (notify entire team), @channel (notify channel members), banner vs feed notifications. Teams settings: Settings → General (theme, auto-start), Notifications (customize per activity type), Privacy (read receipts, priority access), Devices (audio/video settings, test call). Healthcare Teams: HIM Department team (channels: General, Coding, CDI, ROI, Quality, Training — each with relevant files and conversations), project teams (ICD-10-CM FY2026 update preparation, HIPAA risk assessment, EHR optimization), committee teams (Medical Records Committee, Quality Improvement, Compliance), Teams meetings replacing in-person for remote/hybrid work, Teams phone for HIM department communication
    - Cover: Teams hierarchy (Organization → Team → Channel), channel types comparison, meeting features toolbar, Files tab and SharePoint connection

12. **"OneNote: Digital Notebook"** — What is OneNote: digital notebook application — freeform note-taking, organizing information, collaboration, cross-device sync. OneNote structure: Notebooks → Sections (tabs) → Pages → Subpages. Notebooks: major categories (Work, School, Personal, Project-specific). Sections: topic tabs within notebook (color-coded), section groups for deeper organization. Pages: individual notes within a section, unlimited canvas (type anywhere — no fixed text areas), page templates available. Content types: typed text (click anywhere and type, text boxes auto-created), handwriting/drawing (Draw tab — pen, pencil, highlighter, shapes, ruler — works with stylus/touch, converts to text with Ink to Text), images (Insert → Pictures — from file, camera, web), audio recording (Insert → Audio — records while you type, syncs recording to notes — play back and see what was typed at each moment), video (Insert → Video), file attachments/printouts (Insert → File Attachment or File Printout — embed PDF/Word directly in notes), screen clipping (Insert → Screen Clipping or Win+Shift+S → paste), tables (Insert → Table — click grid or add rows/columns, convert to Excel for advanced calculation), links (Ctrl+K — hyperlinks, or paste URL), tags (To Do checkbox, Important, Question, Remember for later, Definition, custom tags — great for action items and review). Organizing: drag pages to reorder, right-click → move/copy pages between sections/notebooks, subpages (indent for hierarchy — parent + child pages), merge containers (drag text boxes together), page color (View → Page Color). Search: Ctrl+E — search across all notebooks, sections, pages (searches text, handwriting via OCR, text in images via OCR — extremely powerful). Sharing & collaboration: Share button → invite to notebook, real-time co-authoring (multiple editors simultaneously), view changes by author (History → Recent Edits), page version history (History → Page Versions). OneNote vs Word: OneNote = freeform notes, research, collection (flexible, unstructured), Word = formal documents (structured, formatted for distribution). OneNote web, desktop, mobile: syncs across all devices (Windows, Mac, iOS, Android, web), always available. Healthcare OneNote: meeting notes notebook (Quality Committee section → pages for each meeting date — agenda, discussion, action items with To Do tags), research/reference notebook (coding guidelines, regulation summaries, exam study notes), project notebook (EHR implementation → sections for each phase, pages for meeting notes, decisions, issues), personal development notebook (training notes, certification study, career goals), clinical documentation reference (CDI query examples, coding tips, audit checklists)
    - Cover: OneNote hierarchy (Notebook → Section → Page), content type variety on a single page, tag types for organization, search across notebooks concept

13. **"Microsoft 365 App Integration & Workflows"** — The M365 ecosystem: apps designed to work TOGETHER, not in isolation. Core integration points: files (OneDrive/SharePoint backbone — any M365 app can access cloud files), identity (single sign-on — one Microsoft account for all apps), search (Microsoft Search — unified search across email, files, people, chat, sites from any M365 app), notifications (all apps feed into Activity/Notification centers). Key integration workflows: Email → Calendar → Teams: receive email with meeting request → automatically added to Outlook calendar → join via Teams meeting link → meeting recording saved to OneDrive → transcription available in Teams. Word → OneDrive → Teams: create policy draft in Word → save to OneDrive → share in Teams channel for review → co-edit with track changes → final version in SharePoint document library. Excel → PowerPoint → Teams: build data dashboard in Excel → insert linked charts into PowerPoint → present in Teams meeting → shared via Teams Files. Outlook → To Do → Planner: flag email for follow-up → appears in Microsoft To Do → create detailed task in Planner (project management — boards, buckets, assignments, due dates, progress tracking). OneNote → Teams → Outlook: take meeting notes in OneNote → linked to Teams meeting → email action items from Outlook. Microsoft Planner: lightweight project management — Plans (projects) → Buckets (categories/phases) → Tasks (individual items with assignee, due date, checklist, attachments, labels, priority). Planner views: Board (Kanban — drag tasks between buckets), Charts (progress visualization), Schedule (calendar view), My Tasks (all tasks assigned to you across all plans). Microsoft Forms: create surveys, quizzes, polls — share via link or embed in Teams/email, responses collected in Excel, auto-analyze with charts. Forms → Excel: responses auto-populate Excel workbook for analysis. ### Unit 4: Security, Administration & Advanced Topics (L14-18)
14. **"Microsoft 365 Security Fundamentals"** — Microsoft 365 security layers: identity (who you are — authentication), device (what you're using — compliance), app (what you're accessing — permissions), data (what you're working with — encryption, DLP). Identity security: Multi-Factor Authentication (MFA) — password + second factor (Microsoft Authenticator app push notification, SMS code, phone call, FIDO2 security key, Windows Hello). MFA setup: Security info (mysignins.microsoft.com) → add authentication methods. Why MFA matters: password alone is insufficient (billions of passwords leaked, credential stuffing attacks, phishing), MFA blocks 99.9% of account compromise attacks. Conditional Access (enterprise): IT-defined policies — require MFA when (signing in from new device, outside office network, accessing sensitive apps), block access when (device non-compliant, risky sign-in detected, impossible travel — login from US then login from Europe within 1 hour). Password security: strong passwords (12+ characters, mix of types), unique per account, password manager recommended (Microsoft Edge built-in, or third-party), Microsoft going passwordless (passkeys, Windows Hello, security keys). Device security: Microsoft Intune (MDM — Mobile Device Management) — IT enrolls/manages devices, enforce policies (encryption required, PIN/biometric required, minimum OS version, approved apps only), remote wipe if device lost/stolen, conditional access checks device compliance before granting access. Email security: Microsoft Defender for Office 365 — anti-phishing (AI detects phishing attempts, safe links — URLs rewritten to check at click time, safe attachments — sandboxed before delivery), anti-malware, anti-spam. Sensitivity labels: classify and protect documents/emails — Confidential (restricted sharing), Highly Confidential (encrypted, restricted access), Internal Only, Public. Applied in Office apps: Home → Sensitivity → choose label → automatically applies encryption and access restrictions. Data Loss Prevention (DLP): IT-configured policies that detect and prevent sharing of sensitive information — scans email/files/chat for patterns (SSN, credit card numbers, MRN patterns, ICD codes) → block, warn, or audit. Healthcare security: MFA mandatory for all EHR access, sensitivity labels on PHI-containing documents ("Confidential — PHI"), DLP policies preventing PHI from being emailed externally or shared via personal OneDrive, Intune managing all workstations and mobile devices, Microsoft Defender protecting against healthcare-targeted phishing/ransomware
    - Cover: M365 security layers diagram, MFA factors illustration, sensitivity label hierarchy, DLP concept (detect → warn/block → audit)

15. **"Privacy, Compliance & HIPAA in Microsoft 365"** — Microsoft 365 compliance center: compliance.microsoft.com — organization's compliance dashboard (managed by IT/compliance team, but users should understand). Microsoft's HIPAA commitment: Microsoft signs BAAs (Business Associate Agreements) for M365 services, HITRUST CSF certification, SOC 2 Type II reports, data encryption at rest (AES-256) and in transit (TLS 1.2+), data residency options (choose where data is stored geographically), regular third-party audits. Shared responsibility model: Microsoft secures the PLATFORM (physical data centers, network, OS, application code), Organization secures the CONFIGURATION (access controls, sharing policies, DLP rules, sensitivity labels, user training, incident response), Users follow POLICIES (don't share PHI inappropriately, use sensitivity labels, report phishing, lock screens, follow acceptable use). Information governance: retention policies (auto-delete or retain documents/email for specified periods — legal hold prevents deletion during litigation), retention labels (apply to individual items — "Retain for 7 years" on medical records), records management (declare items as records — can't be edited/deleted until retention period expires). eDiscovery: legal/compliance team can search all M365 content (email, files, chat, Teams) for litigation or investigation — important for healthcare compliance investigations, OIG audits, malpractice cases. Audit logging: all user and admin activity in M365 logged — who accessed what file, when, from where, what they did — accessible to compliance officers, supports HIPAA audit trail requirements. Communication compliance: monitor Teams chat and email for policy violations (inappropriate content, sensitive information sharing, regulatory compliance), AI-assisted review. Insider risk management: detect risky user behavior (mass file downloads before resignation, unusual data access patterns, policy violations). Privacy settings users should know: Microsoft 365 → Settings → Privacy — diagnostic data settings, connected experiences, what data Microsoft collects. Personal responsibility: don't store PHI in unauthorized locations (personal email, personal OneDrive, USB drives), use approved applications for PHI, report security incidents immediately, complete annual HIPAA training, follow minimum necessary principle
    - Cover: Shared responsibility model (Microsoft vs Organization vs User), retention policy lifecycle, eDiscovery search concept, HIPAA + M365 compliance alignment

Microsoft 365 app (unified): single app combining Word, Excel, PowerPoint + Lens (document scanner), sticky notes, Office documents on the go. Mobile setup: download from App Store (iOS) or Google Play (Android), sign in with work/school account, Intune Company Portal (if organization requires managed device enrollment — installs security policies). Mobile-specific features: document scanning (Lens — take photo → auto-crops, adjusts perspective, converts to PDF/Word/Excel), sign PDFs (open PDF → fill and sign), photo to Excel (take photo of printed table → converts to Excel spreadsheet), QR code reader, voice dictation (in any Office app), mobile formatting (simplified ribbon, touch-optimized). OneDrive mobile: access all files, camera upload (auto-save photos to OneDrive), scan documents (camera → crop → save as PDF/image), offline access (mark files for offline — download before traveling), share files/folders. Teams mobile: full chat functionality, join meetings (audio/video), schedule meetings, share screen from phone, manage notifications (separate from phone notifications), status (Available, Busy, Do Not Disturb, Be Right Back, Appear Offline). 17. **"Microsoft 365 Administration Basics"** — Who manages M365: IT administrators using admin.microsoft.com. Understanding admin concepts helps users: know what to request, understand why certain features are enabled/restricted, communicate effectively with IT, troubleshoot basic issues. Admin center overview (awareness level, not hands-on): Users (add/remove, assign licenses, reset passwords, manage groups), Teams & groups (create/manage Microsoft 365 groups that power Teams, SharePoint, shared mailboxes), Billing (licenses, subscriptions), Settings (organization profile, security defaults, sharing policies), Health (service health — is Outlook/Teams/SharePoint down?), Reports (usage reports — which apps are used, how many active users). License types: Microsoft 365 Business Basic (web apps only, Teams, SharePoint, OneDrive, 1TB), Business Standard (adds desktop apps), Business Premium (adds Intune, Defender, advanced security), Enterprise plans (E1/E3/E5 — escalating features: E5 includes Power BI, advanced compliance, phone system). User management: each user gets a license → determines what apps they can access, IT creates accounts, manages groups, resets passwords (users can also self-service reset at aka.ms/sspr). Groups: Microsoft 365 Groups (powers Teams team + SharePoint site + shared mailbox + Planner + shared OneDrive), Distribution Lists (email only — send to group → all members receive), Security Groups (assign permissions to resources), Mail-enabled Security Groups (both). SharePoint admin: site creation policies (who can create sites), storage quotas per site, sharing settings (internal only vs external guests allowed), hub sites (organize related sites). Exchange admin: mailbox management, email flow rules (organization-wide mail rules), accepted domains, connectors. Teams admin: meeting policies (who can schedule, recording allowed, external guests), messaging policies (giphy, stickers, memes, URL previews), app policies (which third-party apps are allowed). IT support communication: how to submit help desk tickets, what information to provide (error messages, screenshots, steps to reproduce, device/browser info), self-service options (password reset, account recovery, FAQ/knowledge base). Healthcare admin context: IT tightly controls M365 in healthcare (HIPAA compliance requires administrative safeguards), users cannot install unauthorized apps, sharing policies restrict external access, DLP policies auto-enforced, audit logging enabled for all user activity, separate admin for clinical systems (EHR) vs productivity systems (M365) — HIM works with both

18. **"Troubleshooting & Getting Help"** — Common M365 issues and fixes: can't sign in (check password, try aka.ms/sspr for self-service reset, check caps lock, try private/incognito browser — clears cached credentials, contact IT if locked out), app not responding (Task Manager → End Task → reopen, check for updates, repair Office: Settings → Apps → Microsoft 365 → Modify → Quick Repair / Online Repair), sync issues (OneDrive sync errors — check OneDrive icon in system tray for red X or pause icon, right-click → View sync problems, common fix: pause then resume sync, restart OneDrive, check available disk space), file won't open (check file format, check permissions — do you have access?, try opening in web app, check if file is checked out by someone else in SharePoint), email not sending/receiving (check internet connection, check Outbox for stuck messages, try Outlook web — if web works, issue is desktop app, check if attachment is too large — default 25MB limit). Office repair: Settings → Apps → Installed Apps → Microsoft 365 → Modify → Quick Repair (fast, fixes most issues, no internet needed) → Online Repair (thorough, redownloads and reinstalls, requires internet, takes longer). Safe Mode: hold Ctrl while clicking Office app → starts without add-ins (troubleshoot add-in conflicts). Update Office: File → Account → Update Options → Update Now — many issues fixed by updating to latest version. Microsoft support resources: support.microsoft.com (articles, tutorials), F1 key in any app (context-sensitive help), Microsoft Learn (learn.microsoft.com — free training modules, learning paths, certifications), Tech Community (answers.microsoft.com — community forums), Microsoft 365 status (status.office.com — check if services are down), in-app feedback (File → Feedback — report issues directly to Microsoft). Windows troubleshooting: Settings → System → Troubleshoot → Other troubleshooters — built-in troubleshooters for network, audio, printer, Windows Update, Bluetooth. System restore: Settings → System → Recovery → Reset this PC (keep files or remove everything — last resort), System Restore (restore to earlier point — if enabled). Healthcare IT support: most healthcare organizations have dedicated IT help desk (phone, email, ticketing system), escalation paths (Tier 1 = password resets + basic issues → Tier 2 = application issues → Tier 3 = infrastructure/security), document the issue before calling (what were you doing, what happened, error message, when did it start), critical system downtime procedures (EHR downtime — paper forms, backup procedures), know your organization's IT contact information
    - Cover: Common issue → fix decision tree, Office repair options (Quick vs Online), Microsoft support resource guide, healthcare IT escalation path
