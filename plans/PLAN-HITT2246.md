## Lesson Plan (26 Lessons)

### Unit 1: Advanced ICD-10-CM — Complex Diagnosis Coding (L1-8)
1. **"Advanced Sequencing & Principal Diagnosis Selection"** — Complex principal diagnosis scenarios: two or more conditions equally meeting definition of principal diagnosis, symptom followed by definitive diagnosis during same encounter, original treatment plan not carried out, complications of surgery/treatment as reason for admission, symptom code as principal when no definitive diagnosis after study, admission from outpatient surgery, admission from observation. Uncertain diagnoses at discharge: "probable," "suspected," "likely," "questionable," "possible," "still to be ruled out" — code as if confirmed (INPATIENT ONLY, never outpatient). Multiple coding: etiology/manifestation pairs (code first/use additional), sequela coding (condition + cause + 7th character S). Practice scenarios for each rule
   - Cover: Sequencing decision tree, uncertain diagnosis inpatient vs outpatient comparison

2. **"Advanced Diabetes Coding (E08-E13)"** — Full diabetes classification: E08 (due to underlying condition), E09 (drug-induced), E10 (Type 1), E11 (Type 2), E13 (other specified). "With" convention: assumed causal relationship between diabetes and listed complications (no documentation of "due to" needed). Manifestation coding: diabetic retinopathy (stages, laterality, with/without macular edema), diabetic nephropathy (CKD stages), diabetic neuropathy (polyneuropathy, mononeuropathy, autonomic), diabetic foot ulcer (laterality + ulcer code + severity), diabetic ketoacidosis (with/without coma). Type 1 vs Type 2 default rules: if not documented, default Type 2 for adults, Type 1 for children. Insulin use: Type 2 on insulin → add Z79.4; Type 1 on insulin → do NOT add Z79.4. Diabetes in pregnancy (O24). Secondary diabetes and transplant status. Complex multi-manifestation case studies
   - Cover: Diabetes code family tree SVG, manifestation mapping, insulin use decision tree

3. **"Advanced Cardiovascular Coding"** — Hypertension: I10-I16, assumed causal with heart disease (I11), kidney disease (I12), both (I13), secondary hypertension (I15 + underlying cause). Acute MI: I21 (STEMI by artery, NSTEMI), I22 (subsequent MI within 4 weeks), Type 1 vs Type 2 MI (I21.A1), NSTEMI to STEMI conversion. Heart failure: systolic/diastolic/combined, acute/chronic/acute-on-chronic, I50 codes. Atherosclerosis: I25.1 with angina = combination code, native vs graft vs transplanted vessel. Cerebrovascular disease: I60-I69, acute stroke (I63 infarction) vs sequela (I69), laterality, hemorrhagic vs ischemic. Arrhythmias: atrial fibrillation (persistent, paroxysmal, chronic), sick sinus syndrome. Deep vein thrombosis and pulmonary embolism coding. Cardiac device complications (T82). Complex multi-cardiac case studies
   - Cover: MI coding decision tree, hypertension causal relationship diagram, stroke coding flowchart

4. **"Advanced Respiratory & Infectious Disease Coding"** — Pneumonia coding: organism-specific vs unspecified, pneumonia with influenza (J09-J11), aspiration pneumonia (J69), ventilator-associated (J95.851). COPD: J44, acute exacerbation, with acute lower respiratory infection (use both), COPD with asthma (J44 + J45). COVID-19 coding: U07.1 (confirmed), sequencing with manifestations (pneumonia J12.82, ARDS J80, MIS-C M35.81), post-COVID conditions (U09.9). Sepsis coding (CRITICAL — heavily tested): A40-A41 sepsis codes, R65.20 severe sepsis, R65.21 septic shock. Sequencing: sepsis from localized infection (infection first vs sepsis first depending on circumstances of admission), sepsis with organ dysfunction (always add R65.2x), septic shock (R65.21 cannot be principal, sequenced after sepsis + severe sepsis), sepsis due to device/procedure/transfusion (T code sequencing). MRSA/MSSA: B95.61/B95.62 + condition code. HIV: B20 (confirmed), Z21 (asymptomatic), inconclusive (R75), screening (Z11.4), counseling (Z71.7)
   - Cover: Sepsis sequencing flowchart (most important SVG in the course), pneumonia decision tree, HIV coding algorithm

5. **"Advanced Neoplasm & Hematologic Coding"** — Neoplasm table navigation: malignant (primary, secondary, CA in situ), benign, uncertain behavior, unspecified. Sequencing: treatment directed at malignancy (neoplasm first), treatment directed at complication (complication first, neoplasm additional). Anemia associated with malignancy: D63.0 (if due to neoplasm itself) vs D64.81 (if due to antineoplastic chemotherapy). Adverse effects of antineoplastic drugs: T45.1X5 (adverse effect) + manifestation + neoplasm. Current vs history: active treatment = current (C codes), completed treatment with no evidence = history (Z85). Metastatic disease: "metastatic TO" = secondary site, "metastatic FROM" = primary site. Admissions for chemotherapy/immunotherapy/radiation: Z51.11/Z51.12/Z51.0 as principal + neoplasm. CML, CLL, AML, ALL coding specifics. Complex multi-treatment oncology case studies
   - Cover: Neoplasm sequencing decision tree, metastatic coding logic, chemo admission sequencing

6. **"Advanced Pregnancy, Newborn & Pediatric Coding"** — Chapter 15 (O00-O9A): trimester rules (1st: <14 weeks, 2nd: 14-27, 3rd: 28+), 7th character for fetus (0=not applicable/single, 1-5=fetus identification in multiple gestation). Pre-existing vs gestational conditions: pre-existing diabetes (O24.0-O24.3) vs gestational diabetes (O24.4), pre-existing hypertension (O10-O11) vs gestational hypertension (O13) vs pre-eclampsia (O14) vs eclampsia (O15). Supervision of high-risk pregnancy (O09). Outcome of delivery (Z37 always on maternal delivery record). Complications of labor and delivery. Postpartum period: up to 6 weeks. Chapter 16 (P00-P96): ONLY on newborn record, birth status (Z38), prematurity by weight/gestational age, perinatal conditions, maternal conditions affecting newborn. Congenital vs acquired (Chapter 17 Q codes). Pediatric-specific: well-child visits, immunization scheduling
   - Cover: Trimester timeline SVG, pre-existing vs gestational decision tree, fetus 7th character logic

7. **"Advanced Injury, Poisoning & External Cause Coding"** — Chapter 19 (S00-T88): 7th character extensions — A (initial encounter = active treatment), D (subsequent = routine healing), S (sequela = late effect of healed injury). Fracture 7th characters: A/B (initial closed/open), D/G (subsequent routine/delayed healing), K/P (subsequent nonunion closed/open), S (sequela). Multiple injuries: code each, sequence most severe as principal. Poisoning vs adverse effect vs underdosing: Poisoning = wrong drug, wrong dose, wrong person, or taken with alcohol/drugs (T36-T50, 5th/6th character: 1=accidental, 2=intentional self-harm, 3=assault, 4=undetermined), Adverse effect = correct drug/correct dose/correctly administered (5th character 5), Underdosing = took less than prescribed (5th character 6). External cause codes: required for all injuries (place of occurrence Y93, activity Y93, external cause status Y99). Complications of care: T80-T88 (transplant, device, surgical complications), coding vs condition
   - Cover: 7th character decision tree, poisoning vs adverse effect vs underdosing comparison table, fracture 7th character grid

8. **"ICD-10-CM Advanced Case Studies"** — 6-8 complex multi-system case studies requiring advanced sequencing, each presented as a mini patient scenario with discharge summary. Cases cover: sepsis + organ dysfunction + ventilator, diabetes with multiple manifestations + amputation, acute MI + CABG + post-op complication, metastatic cancer + chemotherapy + adverse effects, pregnancy with pre-eclampsia + C-section + newborn coding, traumatic injury with multiple fractures + poisoning. Each case: read documentation → identify all codeable diagnoses → sequence correctly → assign ICD-10-CM codes → explain rationale. Every card is either a case study or a quiz testing case study coding.
   - Cover: Case documentation SVG excerpts, coding worksheets, sequencing rationale

### Unit 2: Advanced ICD-10-PCS — Complex Procedure Coding (L9-14)
9. **"PCS Root Operation Deep Dive: Excision vs Resection vs Destruction"** — Excision (B): cutting out/off WITHOUT replacement, a PORTION of body part (partial nephrectomy, liver biopsy, lumpectomy). Resection (T): cutting out/off ALL of a body part (total nephrectomy, appendectomy, total hysterectomy). Key distinction: entire body part vs portion — "body part" per PCS definition, not anatomical. Destruction (5): physical eradication of all or portion (ablation, cauterization, fulguration, cryotherapy). Detachment (6): ONLY for extremities (amputation), qualifier specifies level (high/mid/low for upper arm/forearm/hand, complete 1st through 5th ray for fingers/toes). Practice scenarios: Is a subtotal thyroidectomy Excision or Resection? (Excision — portion of body part "thyroid gland"). Tonsillectomy? (Resection — entire body part). Polypectomy during colonoscopy? (Excision — portion of body part)
   - Cover: Excision vs Resection comparison table with 10+ examples, Detachment qualifier grid

10. **"PCS Root Operation Deep Dive: Repair, Replacement, Supplement, Alteration"** — Repair (Q): restoring body part to its normal anatomic structure/function — the "not elsewhere classified" root operation (used when no other root operation applies, e.g., suture of laceration, herniorrhaphy without mesh). Replacement (R): putting in biological or synthetic material that PHYSICALLY TAKES THE PLACE of body part (total hip replacement, total knee replacement, skin graft replacing excised skin). Supplement (U): putting in biological or synthetic material that REINFORCES or AUGMENTS body part (hernia repair WITH mesh, breast augmentation with implant, bone graft to augment fusion). Key distinction: Replacement = substitutes, Supplement = reinforces. Alteration (0): modifying body part for cosmetic purposes WITHOUT affecting function (face lift, breast augmentation for cosmetic, liposuction). When the same procedure could be two root operations: documentation determines intent
   - Cover: Repair vs Replacement vs Supplement decision tree, device coding for each, cosmetic vs functional

11. **"PCS Root Operation Deep Dive: Bypass, Drainage, Transplantation"** — Bypass (1): altering route of passage (CABG — coronary artery body part, aorta as body part bypassed from, qualifier identifies bypass to; colostomy, ileostomy, gastric bypass, urinary diversion). Bypass qualifier logic: "from" body part value, "to" qualifier value. Drainage (9): taking/letting out fluids/gases (thoracentesis, paracentesis, I&D of abscess, lumbar puncture). Drainage device: 0=drainage device left in, Z=no device (diagnostic). Transplantation (Y): putting in all or portion of living body part from another individual (kidney, liver, heart, lung, bone marrow). Autologous vs allogeneic vs syngeneic qualifier. Reattachment (M): putting back detached body part (replantation of finger). Transfer (X): moving body part to function for similar but different body part (skin flap, tendon transfer, muscle transfer) — stays connected to blood supply
   - Cover: Bypass code-building exercise SVG, Drainage device decision, Transplant qualifier table

12. **"PCS Approaches & Device Coding"** — All 7 approaches with detailed definitions and examples: Open (0, cutting through skin/mucous membrane AND any other layers), Percutaneous (3, entry through skin/mucous membrane by puncture/minor incision, not visualized directly), Percutaneous Endoscopic (4, entry through skin + visualization by endoscope placed through puncture), Via Natural or Artificial Opening (7, entry through natural/artificial orifice, not visualized), Via Natural/Artificial Opening Endoscopic (8, entry through orifice + endoscope), Via Natural/Artificial Opening with Percutaneous Endoscopic Assistance (F, entry through orifice + percutaneous help — laparoscopic-assisted vaginal hysterectomy), External (X, procedures on skin/mucous membrane or indirectly by force through skin — closed reduction, ear tube removal). Approach determination from operative reports. Device coding: drainage device, monitoring device, infusion device, internal fixation (plate, rod, screw), intraluminal device (stent), synthetic substitute, autologous tissue, nonautologous tissue. Device vs material vs tissue coding. When to code device: ONLY if it remains at end of procedure
   - Cover: Approach comparison table with visual body diagrams, device decision tree, operative report approach identification

13. **"PCS Sections Beyond Medical & Surgical"** — Obstetrics (Section 1): root operations specific to products of conception (Abortion, Delivery, Extraction, Repair, Reposition, Transplantation, Change, Drainage, Insertion, Inspection, Removal, Resection), coding C-section vs vaginal delivery vs assisted delivery. Placement (Section 2): immobilization, compression, packing, traction — short-term device placement. Administration (Section 3): infusions, injections, transfusions — substance value is key (blood products, antineoplastics, vaccines). Measurement & Monitoring (Section 4-5): cardiac output, EEG, fetal monitoring — physiological function + device. Extracorporeal/Osteopathic (Sections 6-8): hemodialysis, plasmapheresis, shock wave lithotripsy, phototherapy. Imaging (Section B): plain radiography, fluoroscopy, CT, MRI, US — body part + contrast + qualifier. Nuclear Medicine (Section C): PET scan, bone scan. Radiation Therapy (Section D): beam radiation, brachytherapy, stereotactic. New Technology (Section X): new devices/substances with temporary codes. When to use which section: surgical procedure vs diagnostic vs therapeutic
   - Cover: Section overview table, Obstetrics root operation comparison, Administration substance examples

14. **"ICD-10-PCS Advanced Case Studies"** — 6-8 complex procedure cases from operative reports. Cases: CABG x3 (build each bypass code character by character), total knee replacement with patella resurfacing (Replacement + Supplement), laparoscopic-assisted vaginal hysterectomy (approach F), spinal fusion with bone graft and instrumentation (Fusion + device coding), colonoscopy with polypectomy and biopsy (multiple procedures through same scope), open reduction internal fixation of femur fracture (Reposition + internal fixation device), kidney transplant from cadaver donor. Each case: read operative report excerpt → identify root operation → determine body part, approach, device, qualifier → build 7-character code → verify in tables. Every card is case-based or quiz.
   - Cover: Operative report excerpts in SVG, character-by-character code building worksheets

### Unit 3: Advanced CPT Coding (L15-19)
15. **"Advanced E/M Coding: Complex Scenarios"** — E/M 2021 MDM mastery: detailed walk-through of each MDM element at each level. Element 1 (problems): self-limited, low severity, moderate severity, high severity — acute/chronic/new/exacerbation counting. Element 2 (data): categories (tests ordered, reviewed, independent interpretation, discussion with external physician, obtaining records), unique test counting, independent interpretation (+1 data point per category). Element 3 (risk): risk table — low (OTC, minor surgery), moderate (prescription management, minor surgery with risk factors, diagnosis requiring IV fluids), high (drug requiring intensive monitoring, emergency major surgery, decision for hospitalization, DNR). Selecting level: meet or exceed 2 of 3 elements. Prolonged services: 99417 for office, time-based add-on (every additional 15 min beyond threshold). Split/shared: substantive portion (>50% of total time, or MDM), must be in-person. Teaching physician: must be present for key/critical portions. Complex case coding with MDM documentation
   - Cover: MDM table SVG (full detail), data element counting worksheet, risk table with examples

16. **"Advanced Surgical Coding: Multi-Procedure & Modifier Mastery"** — Multiple procedure coding: when to use -51 (multiple procedures same session), -59 (distinct procedural service — NCCI unbundling), XE/XS/XP/XU (X{EPSU} modifiers, more specific versions of -59). Modifier stacking rules: order matters for payment (highest RVU first). Complex modifiers: -22 (increased procedural services — needs documentation), -62 (two surgeons, co-surgery), -66 (team surgery), -80 (assistant surgeon), -82 (assistant when qualified resident unavailable). Bilateral procedures: -50 vs RT/LT. Staged procedures: -58 (planned return to OR during global). Related/unrelated procedures during global: -78 (related complication requiring return to OR), -79 (unrelated procedure during global). Add-on codes (+): never reported alone, no -51 needed. Separate procedure designation: bundled unless separate site/session/incision. NCCI bypass with proper modifier use. Complex multi-procedure case studies
   - Cover: Modifier decision tree, NCCI Column 1/2 logic, multi-procedure payment reduction table, XE/XS/XP/XU definitions

17. **"Advanced Radiology, Pathology & Medicine Coding"** — Radiology: professional component (-26) vs technical component (-TC) vs global billing, supervision & interpretation (written report required for professional component). CT/MRI: with contrast, without contrast, with and without (highest paying). Interventional radiology: catheter placement + imaging guidance + procedure (multiple code families). Mammography: screening (77067) vs diagnostic (77065-77066). Radiation oncology: treatment planning, treatment delivery, treatment management (coded per 5 fractions). Pathology: clinical pathology (automated panels 80047-80081) vs anatomic pathology. Surgical pathology levels (88302-88309): level determined by specimen AND examination, most commonly tested. Special stains, immunohistochemistry, molecular pathology (81 codes). Medicine: immunization (admin code + product code), therapeutic injections/infusions (96360-96379 hierarchy: hydration → infusion → push → concurrent), allergy testing, cardiac catheterization coding, pulmonary function, neurology (EEG, EMG/NCS)
   - Cover: Radiology component billing diagram, surgical pathology level table, infusion hierarchy flowchart

18. **"Advanced Anesthesia & Complex Surgical Specialties"** — Anesthesia formula deep dive: (Base units + Time units + Modifying units) × Conversion factor. Time reporting: actual anesthesia time per 15-minute units (start when anesthesiologist begins to prepare patient, end when personal attendance no longer required). Physical status modifiers (P1-P6): P3+ adds units. Qualifying circumstances (99100-99140): extreme age, controlled hypotension, hypothermia, emergency — add units. CRNA billing: with vs without medical direction (QZ, QX, QY, QK modifiers). Monitored anesthesia care (MAC): 00100-01999 + modifier. Neurosurgery: spine coding (approach code + definitive procedure + instrumentation + bone graft — multiple codes per case). Orthopedic: fracture treatment (closed reduction, open reduction, internal fixation, external fixation — treatment type drives code), arthroscopy (diagnostic base + therapeutic add-ons). Cardiovascular: cardiac catheterization (access + catheter placement + injection + imaging), pacemaker/ICD (leads + generator, new vs replacement vs revision). Complex case studies for each specialty
   - Cover: Anesthesia formula SVG with worked example, spine coding component diagram, cardiac cath code family tree

19. **"CPT/HCPCS Advanced Case Studies"** — 6-8 complex outpatient coding scenarios. Cases: E/M with same-day procedure requiring -25 modifier (MDM documentation), multi-procedure surgical case with modifier stacking, interventional radiology (catheter + guidance + procedure), infusion services (multiple drugs, sequential vs concurrent), spine surgery (approach + arthrodesis + instrumentation + graft), emergency department E/M with critical care transition, wound repair (simple + intermediate + complex lengths combined). Each case: read documentation → identify all billable services → assign CPT/HCPCS codes → apply modifiers → check NCCI edits → sequence for payment. CMS-1500 claim completion exercise
   - Cover: Documentation excerpts, code selection worksheets, modifier application logic

### Unit 4: Coding Compliance, Quality & Specialization (L20-24)
20. **"Coding Compliance & Audit Preparation"** — Internal coding audits: sample size determination (statistically valid samples), audit methodology (re-abstract and compare), accuracy rate calculation (agreements/total × 100), benchmark (>95% accuracy target). Error classification: principal diagnosis error, secondary diagnosis error (missed CC/MCC), procedure code error, POA error, discharge status error — impact of each on DRG and payment. External audits: RAC (Recovery Audit Contractor — types of reviews: automated/semi-automated/complex, discussion period, appeals), CERT, MAC, OIG, ZPIC/UPIC. PEPPER reports: target areas (MS-DRGs with high/low rates compared to peers), how to use PEPPER proactively. Coder compliance responsibilities: code what's documented (never assume), query when documentation is unclear (compliant queries), never code from query alone (must be documented), report suspected fraud. AHIMA Standards of Ethical Coding (12 standards in detail). Corrective action plans post-audit
   - Cover: Audit methodology flowchart, accuracy rate calculation, PEPPER report interpretation, ethical coding standards grid

21. **"Clinical Documentation Integrity (CDI) for Coders"** — CDI program structure: concurrent vs retrospective review, CDI specialist role, coder-CDI collaboration. Query process: when to query (clinical indicators suggest higher specificity, conflicting documentation, unclear causality, documentation doesn't support codes assigned by CDI), compliant queries (non-leading, open-ended, reference specific clinical indicators, provide multiple options including "unable to determine," signed by physician). Query types: initial, follow-up, post-discharge (concurrent preferred). What makes a query non-compliant: leading (suggesting a diagnosis), yes/no format, referencing financial impact. CDI metrics: query rate, agreement rate, response rate, CC/MCC capture rate, CMI impact, mortality severity index. CDI impact on quality: PSI, HAC, mortality rates, risk adjustment, Vizient rankings. Documentation improvement examples: "acute respiratory failure" → specificity (hypoxic J96.01 vs hypercapnic J96.02), "heart failure" → type and acuity (systolic vs diastolic, acute vs chronic)
   - Cover: Compliant vs non-compliant query examples SVG, CDI workflow diagram, documentation specificity ladder

22. **"Computer-Assisted Coding (CAC) & Coding Technology"** — Natural Language Processing (NLP): how CAC reads clinical documentation, structured vs unstructured data extraction. CAC workflow: document ingestion → NLP processing → suggested codes → coder review → acceptance/modification/rejection. CAC is an ASSIST tool, not autonomous — coder remains responsible. Encoder tools: logic-based encoding, book-based encoding, automated encoding. Grouper software: DRG grouper, APC grouper, how groupers assign payment classifications. Code editing tools: NCCI edits, MUE checks, LCD/NCD checks, claim scrubbing. Reference tools: Coding Clinic (ICD-10-CM/PCS official guidance, AHA), CPT Assistant (AMA official CPT guidance). Productivity impact: CAC and coder productivity standards, quality vs speed balance. AI and machine learning in coding: emerging capabilities, limitations, validation requirements. Future of coding profession: automation impact, role evolution toward CDI/auditing/analytics
   - Cover: CAC workflow diagram, encoder comparison table, Coding Clinic vs CPT Assistant reference guide

23. **"Specialty Coding: Behavioral Health, Home Health & Beyond"** — Behavioral health coding: DSM-5 and ICD-10-CM Chapter 5 (F codes), substance use hierarchy (use → abuse → dependence, code highest level documented), tobacco use/dependence coding (F17 + Z87.891 history), psychotherapy CPT codes (90832-90853, time-based), psychiatric evaluation (90791-90792), E/M + psychotherapy add-on codes. Home health coding: OASIS-driven coding, PDGM clinical groupings (12 groups determined by principal diagnosis), comorbidity adjustment (HCC-based), timing adjustment (early vs late), admission source (community vs institutional), M-codes for functional status. Hospice coding: terminal diagnosis first, related conditions, V66.7/Z51.5, 4 levels of care. Outpatient rehab coding: PT/OT/SLP evaluation codes (97161-97168), treatment codes (therapeutic exercise 97110, neuromuscular re-ed 97112, manual therapy 97140, gait training 97116), 8-minute rule for timed codes
   - Cover: Substance use coding hierarchy, PDGM classification diagram, 8-minute rule calculation table

24. **"Coding Credentialing & Career Advancement"** — CCS (Certified Coding Specialist, AHIMA): exam format (multiple choice + coding scenarios using ICD-10-CM, ICD-10-PCS, CPT), domains (ICD-10-CM 40%, ICD-10-PCS 14%, CPT 17%, regulatory/compliance 17%, data quality 12%), study strategies. CCS-P (CCS-Physician based): focus on CPT, outpatient ICD-10-CM, E/M. CPC (Certified Professional Coder, AAPC): 150 questions, open-code-book exam, ICD-10-CM + CPT + HCPCS, medical terminology + anatomy. Specialty credentials: CIC (inpatient), COC (outpatient), specialty certifications (cardiology, orthopedics, etc.). CDIP (Clinical Documentation Improvement Practitioner). CHDA (Certified Health Data Analyst). Career ladder: entry-level coder → senior coder → coding lead → coding manager → CDI specialist → HIM director → revenue cycle VP. Salary benchmarks, continuing education requirements, professional development
   - Cover: Credential comparison table, career ladder SVG, exam domain weight charts
