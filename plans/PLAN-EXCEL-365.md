### Unit 1: Excel Foundations (L1-4)
1. **"The Excel Environment & Interface"** — What is Excel: spreadsheet application, part of Microsoft 365 suite, THE dominant tool for data analysis in healthcare and business. Excel vs Google Sheets vs LibreOffice Calc — when to use each (Excel dominates enterprise/healthcare due to advanced features, macro support, Power tools). The Excel interface: Title Bar (file name, AutoSave toggle for OneDrive/SharePoint), Ribbon (tabs: Home, Insert, Page Layout, Formulas, Data, Review, View — each with groups of related commands), Quick Access Toolbar (customizable — Save, Undo, Redo, add frequently used commands), Formula Bar (shows cell contents/formula, expand for long formulas), Name Box (shows active cell address, jump to cells, define names), worksheet grid (1,048,576 rows × 16,384 columns = 17+ billion cells), sheet tabs (bottom — rename, color-code, insert/delete/move/copy sheets), Status Bar (bottom — shows SUM/AVERAGE/COUNT of selected cells, zoom slider, view buttons). Navigation: arrow keys, Ctrl+Home (A1), Ctrl+End (last used cell), Ctrl+arrow (jump to edge of data region), Page Up/Down, Ctrl+G or F5 (Go To dialog — navigate to specific cell/range/special cells). Workbooks vs worksheets: workbook = the file (.xlsx), worksheet = a single sheet/tab within the workbook, organizing with multiple sheets (e.g., Jan/Feb/Mar or Patients/Diagnoses/Procedures). File formats: .xlsx (standard, XML-based), .xls (legacy, pre-2007), .xlsm (macro-enabled), .xlsb (binary — faster for huge files), .csv (comma-separated values — universal, no formatting/formulas), .pdf (for sharing, non-editable). Keyboard shortcuts every user must know: Ctrl+S (save), Ctrl+Z (undo), Ctrl+Y (redo), Ctrl+C/X/V (copy/cut/paste), Ctrl+B/I/U (bold/italic/underline), Ctrl+1 (Format Cells dialog), F2 (edit cell), Esc (cancel entry), Tab (move right), Enter (move down), Ctrl+Shift+L (toggle AutoFilter)
   - Cover: Excel interface anatomy diagram (labeled Ribbon/Formula Bar/Name Box/sheet tabs/Status Bar), navigation shortcut reference card, file format comparison table, workbook vs worksheet concept

2. **"Data Entry, Data Types & Cell Basics"** — Entering data: click cell → type → Enter/Tab. Data types: text/labels (left-aligned by default, any entry starting with letter or apostrophe), numbers (right-aligned, used in calculations, decimal precision, negative numbers), dates (stored as serial numbers — January 1, 1900 = 1, today = ~46,000+, enables date math — subtract dates to get days between), times (stored as fractions of a day — 12:00 PM = 0.5), currency (formatted numbers, not a separate type), logical/boolean (TRUE or FALSE), error values (#VALUE!, #REF!, #NAME?, #DIV/0!, #NULL!, #N/A, #NUM!). Auto Fill: drag fill handle (small square, bottom-right of cell) to extend patterns (months, days, dates, number sequences, custom lists), Flash Fill (Ctrl+E — automatically detects patterns and fills — extracting first names, reformatting phone numbers, splitting/combining data). Editing cells: F2 or double-click to enter edit mode, overtype vs insert mode. Cell references: each cell has an address (column letter + row number = A1, B15, ZZ100), ranges (A1:D10 = rectangular block, A1:A100 = column range, 1:1 = entire row, A:A = entire column). Selecting: click (single cell), click-drag (range), Ctrl+click (non-adjacent cells), Shift+click (extend selection), Ctrl+A (all data/all cells), Ctrl+Shift+End (to last used cell). Row & column operations: insert (right-click → Insert, Ctrl++), delete (Ctrl+−), resize (drag border or double-click for AutoFit, right-click → Row Height/Column Width for exact), hide/unhide (right-click → Hide, useful for intermediate calculations). Copy/Paste Special: Paste Values (strips formulas, pastes only result), Paste Formats (copy formatting only), Paste Formulas, Paste Column Widths, Transpose (rows↔columns), Paste Link. Healthcare data entry: patient lists, encounter logs, coding worksheets, supply inventories — structured data entry for clean analysis
   - Cover: Data type identification guide (text/number/date/error), Auto Fill examples, cell reference notation, Paste Special options grid

3. **"Formulas: Building Blocks of Calculation"** — What is a formula: an expression that calculates a value, ALWAYS starts with = sign. Formula components: constants (numbers typed directly — =5+3), cell references (=A1+B1 — dynamic, updates when referenced cells change), operators (arithmetic: + − * / ^ %, comparison: = > < >= <= <>, text concatenation: & or CONCAT), functions (pre-built formulas — SUM, AVERAGE, IF). Order of operations (PEMDAS): Parentheses first → Exponents → Multiplication/Division (left to right) → Addition/Subtraction (left to right). Example: =10+20*3 = 70 (not 90), =(10+20)*3 = 90. Cell reference types: Relative (A1 — adjusts when copied: copy formula from row 2 to row 3, A1 becomes A2), Absolute ($A$1 — locked, never changes when copied: tax rate, conversion factor), Mixed ($A1 = column locked, row relative; A$1 = row locked, column relative). When to use absolute: when a formula references a constant (tax rate in one cell applied to all rows), lookup tables, header rows. Dollar sign shortcut: F4 toggles through reference types (A1 → $A$1 → A$1 → $A1 → A1). Formula auditing: Trace Precedents (blue arrows showing which cells feed INTO this formula), Trace Dependents (which cells USE this cell), Show Formulas (Ctrl+` — display all formulas instead of values, great for checking work), Evaluate Formula (step through calculation one operation at a time), Error Checking. Common errors: #DIV/0! (dividing by zero — use IFERROR to handle), #VALUE! (wrong data type — text where number expected), #REF! (deleted referenced cell), #NAME? (misspelled function or undefined name), #N/A (lookup value not found), Circular Reference (formula references itself, directly or indirectly — Excel warns, usually an error). Healthcare formula example: calculate total charges (quantity × unit price), length of stay (discharge date − admit date), readmission rate (readmissions / total discharges × 100)
   - Cover: Formula anatomy diagram (= operator cell_ref function), PEMDAS order of operations, relative vs absolute reference behavior when copying, error type reference card with causes and fixes

4. **"Essential Functions: SUM, AVERAGE, COUNT & More"** — What is a function: pre-built formula with a name and defined syntax — =FUNCTION_NAME(argument1, argument2, ...). SUM: adds values — =SUM(A1:A100), can include multiple ranges =SUM(A1:A10, C1:C10), ignores text and blanks. AVERAGE: arithmetic mean — =AVERAGE(range), ignores text and blanks (but counts zeros!). COUNT: counts cells containing numbers — =COUNT(range). COUNTA: counts non-empty cells (any data type) — =COUNTA(range). COUNTBLANK: counts empty cells — =COUNTBLANK(range). MIN / MAX: smallest / largest value — =MIN(range), =MAX(range). MEDIAN: middle value when sorted — =MEDIAN(range), more resistant to outliers than AVERAGE. MODE: most frequently occurring value — =MODE.SNGL(range) for single mode, =MODE.MULT(range) for multiple modes. LARGE / SMALL: kth largest/smallest — =LARGE(range, k), =SMALL(range, k). SUMPRODUCT: sum of products of corresponding arrays — =SUMPRODUCT(array1, array2), extremely versatile — weighted averages, conditional sums without SUMIF. AutoSum: Alt+= shortcut, automatically suggests SUM for adjacent numbers, also accessible from Home tab. Rounding functions: ROUND(value, decimals) — standard rounding, ROUNDUP — always rounds up, ROUNDDOWN — always rounds down, INT — truncates to integer, TRUNC — truncates to specified decimals. ABS: absolute value (removes negative sign). AGGREGATE: powerful function that can ignore errors, hidden rows, subtotals — 19 functions × 7 ignore options. Healthcare applications: average length of stay (ALOS = total patient days / total discharges), case mix index (SUMPRODUCT of DRG weights × cases / total cases), infection rate (infections / patient days × 1000), mortality rate, occupancy rate (patient days / bed days available × 100), bed turnover rate
   - Cover: Core statistical functions comparison table with syntax, AutoSum shortcut demonstration, rounding function behavior comparison, healthcare metric formulas with cell references

### Unit 2: Functions — Intermediate to Advanced (L5-10)
5. **"Logical Functions: IF, AND, OR, NOT"** — IF function: the decision-maker — =IF(logical_test, value_if_true, value_if_false). Logical test: any expression that evaluates to TRUE or FALSE (A1>100, B1="Yes", C1>=D1). Examples: =IF(A1>=90,"A",IF(A1>=80,"B",IF(A1>=70,"C","F"))) — letter grade. Nested IFs: up to 64 levels deep (but don't — use IFS instead after 3-4 levels). IFS function (Excel 365/2019+): =IFS(test1, value1, test2, value2, ..., TRUE, default_value) — cleaner than nested IF, evaluates conditions in order, returns first TRUE match, use TRUE as last condition for default/"else" value. AND: returns TRUE only if ALL conditions are TRUE — =AND(A1>0, A1<100, B1="Active"). OR: returns TRUE if ANY condition is TRUE — =OR(A1="MD", A1="DO", A1="NP"). NOT: reverses TRUE/FALSE — =NOT(A1="Discharged"). Combining: =IF(AND(A1>=18, B1="Consented"), "Eligible", "Ineligible"). SWITCH function: matches a value against a list — =SWITCH(A1, "A", "Excellent", "B", "Good", "C", "Average", "Below Average") — cleaner than nested IFs when comparing one value against multiple options. IFERROR / IFNA: error handling — =IFERROR(A1/B1, 0) returns 0 instead of #DIV/0!, =IFNA(VLOOKUP(...), "Not Found") — catches only #N/A errors. Boolean math: TRUE=1, FALSE=0 in calculations — =SUMPRODUCT((A1:A100="Readmit")*1) counts "Readmit" entries, =SUM(IF(condition, values)) for array-based conditional sums. Healthcare IF examples: patient eligibility determination (age + insurance + consent), readmission flag (if discharge date − readmit date ≤ 30), DRG payment adjustment (if LOS > geometric mean LOS), quality measure pass/fail (if rate meets benchmark)
   - Cover: IF function decision tree flowchart, nested IF vs IFS comparison, AND/OR truth tables, IFERROR wrapping pattern

6. **"Lookup Functions: VLOOKUP, HLOOKUP, XLOOKUP, INDEX-MATCH"** — VLOOKUP: =VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup]) — searches FIRST column of table for a value, returns value from specified column. range_lookup: FALSE = exact match (almost always use this!), TRUE = approximate match (sorted data, used for tax brackets, grade scales). VLOOKUP limitations: only searches leftward → right (first column), breaks if columns inserted/deleted (col_index_num is hard-coded number), only returns first match, exact match is case-insensitive. HLOOKUP: same as VLOOKUP but searches first ROW horizontally — =HLOOKUP(lookup_value, table, row_index, range_lookup), rarely used. XLOOKUP (Excel 365/2021): the modern replacement — =XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode]). XLOOKUP advantages: searches any direction (left, right, up, down), separate lookup and return arrays (no col_index_num), built-in error handling ([if_not_found] argument), match modes (0=exact, -1=exact or next smaller, 1=exact or next larger, 2=wildcard), search modes (1=first to last, -1=last to first, 2=binary ascending, -2=binary descending), can return entire rows/columns. INDEX-MATCH: the power combo — =INDEX(return_range, MATCH(lookup_value, lookup_range, 0)). MATCH returns the position number, INDEX returns the value at that position. Why INDEX-MATCH is preferred by professionals: lookup column can be anywhere, more flexible than VLOOKUP, more efficient on large data sets, doesn't break when columns change. INDEX-MATCH-MATCH: two-dimensional lookup — row AND column lookup. XMATCH (Excel 365): modern MATCH — same improvements as XLOOKUP (match modes, search modes). Healthcare lookup examples: ICD-10-CM code description lookup, DRG weight lookup from table, physician NPI → name lookup, CPT code → RVU value, patient MRN → demographic data, charge code → department mapping
   - Cover: VLOOKUP anatomy diagram, XLOOKUP vs VLOOKUP feature comparison, INDEX-MATCH concept flow, lookup function selection decision tree

7. **"Text Functions & Data Cleaning"** — Why text functions matter: real healthcare data is MESSY — inconsistent names, mixed case, extra spaces, combined fields that need splitting, codes embedded in text. Core text functions: LEFT(text, num_chars) — extract from beginning, RIGHT(text, num_chars) — extract from end, MID(text, start, num_chars) — extract from middle, LEN(text) — character count, FIND(find_text, within_text, [start]) — position of text (case-sensitive, returns error if not found), SEARCH(find_text, within_text, [start]) — like FIND but case-insensitive and supports wildcards (* and ?). Changing case: UPPER(text) — "JOHN SMITH", LOWER(text) — "john smith", PROPER(text) — "John Smith" — critical for standardizing patient names. Cleaning functions: TRIM(text) — removes extra spaces (leading, trailing, and reduces multiple internal spaces to one), CLEAN(text) — removes non-printable characters (from imported data), SUBSTITUTE(text, old_text, new_text, [instance]) — replace specific text, REPLACE(old_text, start, num_chars, new_text) — replace by position. Combining text: CONCATENATE(text1, text2, ...) or & operator — ="Last: "&A1&", First: "&B1, TEXTJOIN(delimiter, ignore_empty, text1, text2, ...) — Excel 365 — =TEXTJOIN(", ", TRUE, A1:A10) joins with comma. Conversion functions: VALUE(text) — converts text-number to number (imported data often stored as text), TEXT(value, format_code) — formats number as text — =TEXT(A1,"MM/DD/YYYY"), =TEXT(B1,"$#,##0.00"), =TEXT(C1,"000000") — leading zeros. Flash Fill (Ctrl+E): Excel's pattern recognition — type one or two examples and Flash Fill detects the pattern: extracting area codes, reformatting dates, splitting full names into first/last, combining address fields. Healthcare text scenarios: parsing patient names (split "Smith, John A" into last/first/middle), extracting diagnosis codes from text strings, standardizing physician names across data sets, cleaning imported registry data, formatting MRN with leading zeros, extracting procedure laterality from description text
   - Cover: Text function cheat sheet (LEFT/RIGHT/MID/LEN with examples), TRIM/CLEAN before-and-after, Flash Fill pattern detection examples, healthcare data cleaning workflow

8. **"Date & Time Functions"** — How Excel stores dates: serial numbers (Jan 1, 1900 = 1, today ≈ 46,000+), enables date arithmetic — subtract two dates = number of days between them. Date entry: type dates in recognizable formats (1/15/2026, 15-Jan-2026, January 15, 2026), Excel converts to serial number and formats. TODAY() — returns current date (volatile, updates on recalculation), NOW() — returns current date AND time. Date extraction: YEAR(date), MONTH(date), DAY(date) — extract components, WEEKDAY(date, [return_type]) — day of week (1=Sunday through 7=Saturday by default), WEEKNUM(date) — week number of year. Date construction: DATE(year, month, day) — build a date from components, useful for dynamic dates — =DATE(2026, MONTH(A1)+6, DAY(A1)) adds ~6 months. Date arithmetic: =B1-A1 (discharge − admit = LOS in days), EDATE(start_date, months) — add/subtract months exactly, EOMONTH(start_date, months) — end of month N months away, DATEDIF(start_date, end_date, unit) — difference in "Y"ears/"M"onths/"D"ays (undocumented but works — great for calculating patient age). NETWORKDAYS(start, end, [holidays]) — working days between dates (excludes weekends, optional holiday list), WORKDAY(start, days, [holidays]) — date N working days from start. Time functions: HOUR(time), MINUTE(time), SECOND(time), TIME(hour, minute, second). Time arithmetic: Excel stores time as fractions (1 hour = 1/24 = 0.041667), subtract times for duration, format as [h]:mm for durations over 24 hours (total hours, not rolling over). Healthcare date/time applications: Length of Stay (discharge date − admit date, note: same-day = 1 day by convention), patient age (DATEDIF(DOB, TODAY(),"Y")), time to treatment (ED arrival time → first provider contact), appointment scheduling, claims filing timely (date of service → claim submission deadline), record retention dates (discharge date + retention years), days in A/R (accounts receivable aging), FMLA leave tracking, credentialing expiration dates
   - Cover: Excel date serial number concept, date function reference card, LOS calculation example, time arithmetic with formatting

9. **"SUMIFS, COUNTIFS, AVERAGEIFS — Conditional Aggregation"** — SUMIF: =SUMIF(range, criteria, [sum_range]) — sum values where condition is met. SUMIFS: =SUMIFS(sum_range, criteria_range1, criteria1, criteria_range2, criteria2, ...) — sum with MULTIPLE conditions (AND logic). Note syntax difference: SUMIF puts sum_range last (optional), SUMIFS puts sum_range FIRST. COUNTIF: =COUNTIF(range, criteria) — count cells meeting one condition. COUNTIFS: =COUNTIFS(criteria_range1, criteria1, criteria_range2, criteria2, ...) — count with multiple conditions. AVERAGEIF / AVERAGEIFS: same pattern — average values meeting conditions. Criteria syntax: exact match ("Cardiology"), comparison (">100", "<="&D1), wildcards (* = any characters, ? = single character — "J*" matches any name starting with J, "????" matches exactly 4 characters), not equal ("<>Discharged"), dates (">"&DATE(2026,1,1)), blank/not blank ("", "<>"). Using cell references in criteria: =">"&E1 (dynamic threshold), combining text with cell reference. MAXIFS / MINIFS (Excel 365/2019): =MAXIFS(max_range, criteria_range, criteria) — maximum value meeting conditions, same for MINIFS. Combining conditional functions: =COUNTIFS(range1, criteria1) / COUNTA(range1) — percentage meeting criteria, =SUMIFS(...) / COUNTIFS(...) — conditional average with more control, =COUNTIFS(range, ">="&lower, range, "<"&upper) — counting within a range (frequency distribution). Healthcare applications: total charges by department (SUMIFS — Department="Cardiology"), count discharges by payer (COUNTIFS — Payer="Medicare", DischargeDate>=start, DischargeDate<=end), average LOS by DRG (AVERAGEIFS), count patients by diagnosis and age range, readmission count by condition within 30 days, charges by physician and date range, infection count by unit and month
   - Cover: SUMIF vs SUMIFS syntax comparison, criteria syntax reference card, COUNTIFS with date range example, healthcare conditional aggregation dashboard concept

10. **"Advanced Functions: Financial, Math & Array Formulas"** — Financial functions (useful for healthcare finance): PMT(rate, nper, pv) — loan payment calculation (equipment financing, capital budgets), FV(rate, nper, pmt, pv) — future value, PV(rate, nper, pmt, fv) — present value, NPV(rate, value1, value2, ...) — net present value (evaluating capital equipment purchases), IRR(values) — internal rate of return. Math functions: SUMPRODUCT(array1, array2, ...) — versatile workhorse: weighted averages (=SUMPRODUCT(weights, values)/SUM(weights)), conditional calculations without SUMIFS, multi-criteria counting. MOD(number, divisor) — remainder after division (useful for alternating row colors, scheduling patterns). ROUND/ROUNDUP/ROUNDDOWN — already covered, essential for financial accuracy. RAND() / RANDBETWEEN(bottom, top) — random numbers (random sampling for audits, simulation). Statistical: STDEV.S (sample standard deviation), VAR.S (variance), PERCENTILE.INC / PERCENTILE.EXC — percentile calculations, QUARTILE.INC — quartile values, RANK.EQ / RANK.AVG — ranking values in a data set, FREQUENCY(data_array, bins_array) — frequency distribution (Ctrl+Shift+Enter for legacy). Dynamic arrays (Excel 365): formulas that return multiple values — spill into adjacent cells automatically. SORT(array, [sort_index], [sort_order]) — dynamic sorting, SORTBY(array, by_array, [order]) — sort by another column, FILTER(array, include, [if_empty]) — dynamic filtering — =FILTER(A2:D100, B2:B100="Cardiology", "None"), UNIQUE(array) — unique values list, SEQUENCE(rows, [cols], [start], [step]) — generate number sequences, RANDARRAY(rows, cols, min, max, integer) — random array. Array formulas (legacy): Ctrl+Shift+Enter (CSE) — formulas that process arrays — {=SUM(IF(A1:A100="Cardiology", C1:C100))} — largely replaced by dynamic arrays in Excel 365. Healthcare applications: case mix index calculation (SUMPRODUCT of DRG weights), random audit sampling (RANDBETWEEN + INDEX), statistical process control (STDEV for control limits), cost-benefit analysis (NPV, IRR), patient ranking by acuity score, dynamic department-filtered patient lists
    - Cover: SUMPRODUCT versatility examples, dynamic array spill concept, FILTER function for healthcare data, financial function healthcare applications

### Unit 3: Data Presentation & Formatting (L11-13)
11. **"Number Formatting, Cell Styles & Conditional Formatting"** — Number formats: General (default, no specific format), Number (decimal places, thousands separator, negative number display), Currency ($1,234.56 — dollar sign hugs number), Accounting ($  1,234.56 — dollar signs align in column, zeros shown as dashes), Percentage (multiplies by 100, adds %), Date (Short: 1/15/2026, Long: January 15, 2026, custom), Time (1:30 PM, 13:30), Fraction (1/4 instead of 0.25), Scientific (1.23E+05), Text (treats everything as text — for MRN, zip codes with leading zeros, SSN formatting), Custom (build your own — "000-00-0000" for SSN, "000000" for 6-digit MRN, "#,##0;(#,##0);—" for positive/negative/zero). Format Cells dialog (Ctrl+1): Number tab (formats), Alignment tab (horizontal/vertical alignment, wrap text, merge cells, text orientation/rotation, indent, shrink to fit), Font tab (typeface, size, color, bold/italic, underline, strikethrough, superscript/subscript), Border tab (line style, color, preset/custom borders), Fill tab (background color, pattern, gradient), Protection tab (locked, hidden — works with sheet protection). Cell styles: predefined formatting combinations (Title, Heading 1-4, Input, Output, Calculation, Good/Bad/Neutral), custom cell styles, style consistency across workbook. Conditional formatting: rules that change cell appearance based on value. Rule types: Highlight Cell Rules (Greater Than, Less Than, Between, Equal To, Text That Contains, Duplicate Values), Top/Bottom Rules (Top 10 Items, Top 10%, Above/Below Average), Data Bars (in-cell bar charts), Color Scales (2-color, 3-color gradient — red-yellow-green for performance), Icon Sets (arrows, flags, stars, traffic lights). Custom rules with formulas: =AND(B2>30, C2="Medicare") — apply to specific complex conditions. Managing rules: priority order (top rule wins), Stop If True, Edit/Delete rules. Healthcare formatting: color-code overdue records (red if days > 30), flag abnormal lab values, data bars for charges, icon sets for quality scores (green check/yellow exclamation/red X), highlight readmissions, format MRN/SSN with custom number formats
    - Cover: Number format comparison table, conditional formatting rule types with visual examples, custom number format codes, icon set quality dashboard example

12. **"Charts & Data Visualization"** — Why visualize: humans process images 60,000x faster than text, charts reveal patterns/trends/outliers that tables hide. Chart types and when to use each: Column chart (vertical bars — comparing categories, discrete data), Bar chart (horizontal — comparing categories with long labels), Line chart (trends over time, continuous data), Area chart (like line but filled — cumulative totals, part-to-whole over time), Pie chart (composition/proportion of a whole — USE SPARINGLY, max 5-6 slices, always label percentages), Doughnut chart (like pie but with hole — compare multiple series), Scatter/XY plot (relationship between two variables, correlation, regression), Bubble chart (scatter + third variable as bubble size), Histogram (frequency distribution — bin ranges, bell curves), Box & Whisker (statistical distribution — median, quartiles, outliers), Waterfall (showing how values build up or break down — revenue → expenses → profit), Funnel (stages in a process — claims submitted → processed → paid), Map chart (geographic data), Treemap (hierarchical proportions), Sunburst (hierarchical ring chart), Combo chart (two chart types on same axes — line + column for trend + comparison). Creating charts: select data → Insert tab → Chart type (Excel recommends charts based on data), Chart Design tab (styles, layouts, switch row/column, change chart type), Format tab (shape fills, outlines, effects). Chart elements: chart title (descriptive, not "Chart 1"), axis titles (include units), data labels (on charts with few data points), legend (position — usually bottom or right), gridlines (major for reference, remove minor clutter), trendline (linear, exponential, moving average — R² value for fit), error bars. Chart design principles: minimize chartjunk (Edward Tufte — remove unnecessary gridlines, borders, 3D effects, decorations), maximize data-ink ratio, use consistent and accessible colors, label directly when possible (vs relying on legend), start Y-axis at zero for bar/column charts (avoid misleading), appropriate aspect ratio. Sparklines: tiny in-cell charts (line, column, win/loss) — show trends alongside data in tables, great for dashboards. Healthcare chart examples: monthly admission trends (line), charges by department (bar), payer mix (pie), LOS distribution (histogram), infection rate control chart (line with UCL/LCL), readmission rates over time with benchmark line (combo), DRG case volume treemap
    - Cover: Chart type selection decision tree, chart anatomy diagram (title/axes/legend/data labels/gridlines), before-and-after chartjunk cleanup, sparkline dashboard example

13. **"Page Layout, Printing & Sharing"** — Page Layout tab: margins (Normal, Wide, Narrow, Custom), orientation (Portrait vs Landscape — wide data needs landscape), size (Letter, Legal, A4), print area (set specific range to print — Page Layout → Print Area → Set), page breaks (preview mode — blue dashed lines, drag to adjust, Insert → Page Break), background (decorative, doesn't print — use for on-screen identification). Print scaling: Fit Sheet on One Page, Fit All Columns on One Page, Fit All Rows on One Page, custom scaling percentage — avoid shrinking too small to read. Headers & Footers: Insert tab → Header & Footer (or Page Layout view), predefined options (page number, date, file name, sheet name), custom placement (left/center/right section), different first page, different odd/even pages, &[Page] of &[Pages] format. Print Titles: Page Layout → Print Titles → Rows to Repeat at Top / Columns to Repeat at Left — CRITICAL for multi-page reports (header row prints on every page). Print Preview (Ctrl+P): see exactly what will print, navigate pages, adjust settings. Print settings: printer selection, page range, active sheets vs entire workbook vs selection, collated vs uncollated, one-sided vs two-sided. Saving & sharing: Save As PDF (File → Save As → PDF, or File → Export → Create PDF/XPS — preferred for sharing reports that shouldn't be edited), email (File → Share → Email), OneDrive/SharePoint (cloud storage, co-authoring — real-time collaboration, version history), protect workbook/sheet (protect sheet = lock/unlock specific cells — unlock input cells, lock formula cells; protect workbook = prevent adding/deleting/renaming sheets; password protection on file open). Collaboration features: comments (threaded discussions on cells), notes (simple annotations — formerly "comments" in older versions), track changes (Review → Track Changes — highlight additions/deletions, accept/reject), co-authoring (multiple users editing simultaneously via OneDrive/SharePoint, AutoSave). Healthcare sharing: patient data → PDF only (never send editable .xlsx with PHI via email), de-identification before sharing for research, HIPAA considerations for cloud storage (BAA with Microsoft for M365)
    - Cover: Print settings checklist, Print Titles concept diagram, sheet protection (lock formulas, unlock input cells), sharing method comparison with HIPAA notes

### Unit 4: Data Management & Analysis (L14-18)
14. **"Sorting, Filtering & Tables"** — Sorting: reorder data by one or more columns. Single-column sort: Data tab → Sort A to Z / Z to A, or right-click → Sort. Multi-level sort: Data → Sort dialog → Add Level — sort by Department THEN by LastName THEN by Date. Sort options: values (numbers, text, dates), cell color, font color, cell icon. Custom sort order: define custom lists (High/Medium/Low instead of alphabetical). Caution: always select ALL data columns before sorting (or use Tables) — sorting only one column scrambles your data. Filtering: AutoFilter — Ctrl+Shift+L or Data → Filter — dropdown arrows on each column header. Filter types: by value (check/uncheck items), by text (Contains, Begins With, Ends With, wildcard), by number (Greater Than, Less Than, Between, Top 10, Above/Below Average), by date (This Month, Next Quarter, Year to Date, custom date range), by color/icon. Clear filter: dropdown → Clear Filter From "Column". Advanced Filter: Data → Advanced — criteria range on worksheet, AND/OR logic, filter in place or copy to another location, unique records only. Excel Tables (Ctrl+T): structured data with special features — auto-expanding (add data below, table grows), structured references (=[@Column1]+[@Column2] instead of =A2+B2, makes formulas readable), auto-filter buttons, banded rows for readability, auto-fill formulas down column, Total Row (toggle on — SUBTOTAL functions: Sum, Average, Count, Min, Max, more), table styles (light, medium, dark themes), Table Name (rename in Design tab — use in formulas =SUMIF(TableName[Department],"Surgery",TableName[Charges])). Converting: Table → Range (Design → Convert to Range), Range → Table (Ctrl+T). Subtotals (non-table): Data → Subtotal — groups data and calculates subtotals by category (at each change in..., use function, add subtotal to), creates outline levels (expand/collapse groups). Healthcare applications: sort patients by admission date, filter encounters by DRG, table of coding productivity (auto-totals), filter claims by denial reason and date range, subtotal charges by department
    - Cover: Multi-level sort concept, AutoFilter options overview, Excel Table features diagram, structured reference syntax comparison (Table vs standard)

15. **"PivotTables: Foundations"** — What is a PivotTable: interactive summary tool that reorganizes (pivots) data to analyze from different perspectives WITHOUT changing the source data — the single most powerful analysis tool in Excel. When to use: summarizing large data sets, cross-tabulating data (rows × columns), answering "how much by category" questions, exploring data interactively. Anatomy: Rows area (categories down the left — Department, Physician, DRG), Columns area (categories across the top — Month, Payer, Gender), Values area (what to calculate — SUM of Charges, COUNT of Patients, AVERAGE of LOS), Filters area (page-level filter — Year, Facility). Creating: select data range or Table → Insert → PivotTable → choose location (new sheet recommended for large analysis). PivotTable Fields pane: drag fields to Rows, Columns, Values, Filters areas — rearrange by dragging between areas. Value Field Settings: change calculation (Sum, Count, Average, Max, Min, Product, Count Numbers, StdDev, Var), number formatting (apply consistent formatting to values). Refreshing: PivotTables do NOT auto-update when source data changes — right-click → Refresh (or Analyze → Refresh), Refresh All (Ctrl+Alt+F5) refreshes all PivotTables/connections. Data source: PivotTable and source data are linked — changes to source require refresh, adding rows requires updating data source range (use Excel Tables as source — auto-expands). Multiple value fields: drag same field to Values twice (e.g., Count of PatientID AND Sum of Charges), or different fields (Sum of Charges, Average of LOS, Count of Encounters). Layout: Compact Form (default, indented), Tabular Form (column per field, best for further analysis — copy-paste friendly), Outline Form (expanded with subtotals). Subtotals and Grand Totals: show/hide for rows and columns, subtotal at top or bottom of group. Healthcare PivotTable #1: encounter data → rows: Department, columns: Payer, values: COUNT of encounters — instantly see encounter volume by department and payer. Healthcare PivotTable #2: charges by DRG and month, average LOS by physician and service line
    - Cover: PivotTable anatomy (Rows/Columns/Values/Filters areas), field pane drag-and-drop concept, layout form comparison (Compact vs Tabular vs Outline), healthcare PivotTable example with source data → result

16. **"PivotTables: Advanced Techniques"** — Grouping: right-click a field → Group — dates (group by Month, Quarter, Year automatically — drag Date to Rows, right-click → Group → select levels), numbers (age ranges — group by 10: 0-9, 10-19, ..., custom bins), text (select items → right-click → Group — create custom categories). Calculated fields: create new fields from existing fields — PivotTable Analyze → Fields, Items & Sets → Calculated Field — =Charges/LOS (per-diem rate), =Readmit/Encounters*100 (readmission rate). Calculated items: custom members within a field — less common, use carefully. Show Values As: change how values display WITHOUT changing the underlying calculation — % of Grand Total, % of Column Total, % of Row Total, % of Parent Row/Column, Running Total In, Rank Smallest to Largest/Largest to Smallest, Difference From (compare to previous month, same month last year), % Difference From. Slicers: visual filter buttons — Insert → Slicer — click to filter, Ctrl+click for multi-select, connect one slicer to multiple PivotTables (right-click slicer → Report Connections). Timelines: date-specific slicer — filter by Years, Quarters, Months, Days — drag to select date range. PivotCharts: chart directly from PivotTable — Insert → PivotChart — interactive (changes when PivotTable changes, slicers/timelines filter both). Dashboard building: multiple PivotTables from same data source + slicers connected to all + PivotCharts = interactive dashboard — filter by Department using one slicer and ALL tables/charts update simultaneously. Data Model PivotTables: PivotTables from multiple tables with relationships (mini Power Pivot) — check "Add this data to the Data Model" when creating, create relationships between tables, analyze across tables without VLOOKUP. Healthcare advanced PivotTable: build a quality dashboard — PivotTable 1: encounters by month (line chart), PivotTable 2: charges by payer (pie chart), PivotTable 3: top 10 DRGs by volume (bar chart), connected slicers for Department, Payer, Date — one-click filtering of entire dashboard
    - Cover: Date grouping step-by-step, Show Values As options with examples, slicer connected to multiple PivotTables concept, interactive dashboard layout mockup

17. **"Data Validation & Protection"** — Data validation: restrict what can be entered in cells — prevent errors at the source. Validation types: Whole Number (between min/max), Decimal (between min/max), List (dropdown from range or comma-separated values — most common and useful), Date (between start/end), Time (between start/end), Text Length (between min/max — SSN must be exactly 9 characters), Custom (formula-based — any formula returning TRUE/FALSE). Setting up: Data → Data Validation → Settings tab (type + criteria), Input Message tab (title + message shown when cell selected — instructions for the user), Error Alert tab (style: Stop = can't enter invalid, Warning = warns but allows, Information = FYI only; title + error message). Dropdown lists: Data Validation → List → Source = range or "Option1,Option2,Option3" — creates dropdown in cell. Best practices: source dropdowns from a named range on a reference sheet (add/remove options without changing validation), use INDIRECT with named ranges for dependent dropdowns (cascading — select State → City list updates). Circle Invalid Data: Data → Validation → Circle Invalid Data — red circles around cells that violate rules (great for auditing existing data). Custom validation formulas: =COUNTIF(A:A,A1)=1 (prevent duplicates), =AND(LEN(A1)=10, LEFT(A1,1)<>"0") (custom format check), =A1<=TODAY() (date cannot be in future). Sheet protection: Review → Protect Sheet — unlock input cells first (Format Cells → Protection → uncheck Locked), lock everything else, optional password. Allow specific users to edit ranges (Windows only). Workbook protection: Review → Protect Workbook — prevent structure changes (add/delete/rename sheets). File encryption: File → Info → Protect Workbook → Encrypt with Password — AES encryption, cannot be recovered if password lost. Marking as Final: soft protection — displays "Read-Only" banner, easily bypassed — use for intent signaling, not security. Healthcare validation: dropdown for discharge disposition codes, date validation (admit ≤ discharge), MRN format validation (10-digit numeric), payer dropdown (standardized list), gender dropdown (F/M/X/U), ICD-10 code format validation (letter + digits + decimal pattern), required fields highlighted
    - Cover: Validation type selection guide, dropdown list setup steps, protection layer hierarchy (cell → sheet → workbook → file), healthcare validation examples

18. **"What-If Analysis & Scenario Tools"** — What-If Analysis: answering "what happens if we change X?" without modifying actual data. Goal Seek: Data → What-If Analysis → Goal Seek — find the INPUT value needed to reach a desired RESULT. Set cell (formula cell) = To value (desired result), By changing cell (input cell). Example: what volume of discharges needed to reach $5M revenue? Goal Seek finds the answer. Data Tables: test multiple values for one or two variables simultaneously. One-variable data table: input values in column, formula references one cell, results fill automatically — e.g., test different staffing levels → impact on productivity. Two-variable data table: two inputs (row input + column input), results in grid — e.g., price × volume matrix showing revenue. Scenario Manager: Data → What-If Analysis → Scenario Manager — save multiple "what if" scenarios with named sets of input values, switch between them, generate summary report. Example: "Best Case" (high volume, low costs), "Worst Case" (low volume, high costs), "Most Likely" — compare all scenarios side by side. Solver: Data → Solver (add-in — may need to enable in File → Options → Add-ins) — optimization tool, finds optimal value for a target cell by changing multiple variable cells subject to constraints. Components: objective (maximize, minimize, or set to value), variable cells (what Solver can change), constraints (limits — budget ≤ $100,000, staff ≥ 5, overtime ≤ 40 hours). Solver methods: Simplex LP (linear problems), GRG Nonlinear (smooth nonlinear), Evolutionary (complex/discontinuous). Solver example: maximize patient throughput by optimizing staff scheduling subject to budget and labor constraints. Forecast Sheet: Data → Forecast Sheet — automatic time series forecast with confidence intervals, uses exponential smoothing (ETS) algorithm, requires historical date + value data, creates chart with forecast and confidence bands. Healthcare applications: Goal Seek — what CDI query rate needed to increase CMI by 0.05?, Data Tables — sensitivity analysis of charges at different volumes and rates, Scenario Manager — budget planning (optimistic/pessimistic/expected), Solver — optimal OR scheduling to maximize utilization within staffing constraints, Forecast Sheet — predict next 12 months of admission volume
    - Cover: Goal Seek concept diagram, data table (one-variable and two-variable) layout, Scenario Manager summary report, Solver setup with objective/variables/constraints

### Unit 5: Power Tools & Automation (L19-23)
19. **"Power Query: Import, Transform & Clean Data"** — What is Power Query: Excel's ETL (Extract, Transform, Load) engine — import data from virtually any source, transform/clean it, load into Excel. Replaces manual data cleaning — repeatable, refreshable. Accessing: Data tab → Get Data (full menu), or Get & Transform group shortcuts (From Table/Range, From Text/CSV, From Web). Data sources: Excel files (other workbooks, different sheets), CSV/text files (delimiter options — comma, tab, semicolon, fixed width), databases (SQL Server, Access, Oracle, MySQL — connect directly), web pages (import HTML tables), folders (combine multiple files — all CSVs in a folder), SharePoint, OData feeds, PDF tables, JSON, XML. Power Query Editor: ribbon (Home, Transform, Add Column, View), Applied Steps pane (every transformation recorded as a step — replayable, editable, deletable), preview pane (shows data transformation results), formula bar (M language — each step is an M formula). Core transformations: Remove Columns (select → right-click → Remove), Remove Rows (remove top/bottom/blank/duplicate/error rows), Filter Rows (click column dropdown — same as Excel filter but applies during import), Change Type (text, number, date, whole number — CRITICAL first step), Replace Values (find and replace within column), Split Column (by delimiter — comma, space, custom; by number of characters; by positions), Merge Columns (combine with delimiter), Rename Columns, Unpivot Columns (transform wide data to long — columns become rows, critical for analysis), Pivot Columns (long to wide), Fill Down (replace nulls with value above — for grouped data), Group By (aggregate — sum, count, average by category), Add Column from Examples (type example values, Power Query detects pattern), Custom Column (write M formula for calculated column), Conditional Column (if-then-else logic for new column). Append Queries: stack data from multiple sources (UNION — same columns), Merge Queries: join data from different tables (like VLOOKUP but more powerful — inner/left/right/full/anti join types). Loading: load to Table (worksheet), load to PivotTable, load to Data Model (Power Pivot), Connection Only (refresh later). Refresh: Data → Refresh All — reruns all Power Query steps on fresh data — entire data cleaning pipeline runs automatically. Healthcare Power Query: import monthly discharge data from 12 CSV files → append into one table → clean names → fix dates → remove duplicates → load to PivotTable for analysis — what took hours of manual work now takes one click to refresh
    - Cover: Power Query ETL flow (source → transform → load), Power Query Editor interface anatomy, core transformation steps visual guide, append vs merge concept diagram

20. **"Power Pivot & Data Modeling"** — What is Power Pivot: in-memory data modeling and analysis engine built into Excel — enables working with MILLIONS of rows (far beyond Excel's 1M row limit), creating relationships between multiple tables, and writing DAX formulas for advanced calculations. Enabling: File → Options → Add-ins → COM Add-ins → check Microsoft Power Pivot for Excel. Why Power Pivot vs regular PivotTables: handles massive data sets (100M+ rows), multiple related tables (star schema — fact table + dimension tables), DAX formulas (far more powerful than standard Excel formulas), reusable data model, foundation for Power BI. Data Model: collection of tables with defined relationships — imported via Power Query or added directly. Creating relationships: Power Pivot → Diagram View — drag field from one table to matching field in another (like a mini database — primary key to foreign key). Relationship types: one-to-many (most common — one department has many encounters), one-to-one (rare), many-to-many (requires bridge table or DAX). Star schema: fact table (center — encounters, charges, claims — contains measures and foreign keys) surrounded by dimension tables (Department, Physician, Payer, Patient, Date — descriptive attributes). DAX (Data Analysis Expressions): formula language for Power Pivot, similar to Excel functions but designed for tables and relationships. Key DAX functions: CALCULATE (change filter context — most important DAX function), SUM / AVERAGE / COUNT / MIN / MAX (aggregate), COUNTROWS (count rows in table), DISTINCTCOUNT (unique values), RELATED (pull value from related table — like VLOOKUP through relationship), ALL (remove filters), FILTER (return filtered table), VALUES (unique values in column), IF (conditional). DAX measures vs calculated columns: measures (dynamic, calculated at query time based on PivotTable context — preferred for aggregations), calculated columns (static, calculated row-by-row when data refreshes — for categorizations, row-level calculations). Time intelligence: DAX excels at time-based calculations — TOTALYTD (year-to-date), SAMEPERIODLASTYEAR (compare to prior year), DATEADD (shift dates), DATESYTD / DATESMTD / DATESQTD (date ranges). Healthcare Power Pivot: Encounters fact table + Patient dimension + Provider dimension + Payer dimension + Date dimension + DRG dimension — build a comprehensive analytics model: total charges by any combination of dimensions, readmission rates over time, CMI trends by quarter, payer mix analysis, physician productivity, year-over-year comparison — all from one data model powering multiple PivotTables
    - Cover: Star schema diagram (fact + dimensions), DAX CALCULATE concept, measure vs calculated column comparison, Power Pivot relationship diagram view

21. **"Macros & VBA Introduction"** — What is a macro: recorded sequence of actions that can be replayed — automate repetitive tasks. Recording a macro: View → Macros → Record Macro (or Developer tab → Record Macro) — name (no spaces, start with letter), shortcut key (optional — Ctrl+letter), store in (This Workbook, Personal Macro Workbook — available in all files, New Workbook), description. Recording performs: every action recorded as VBA code — clicking, typing, formatting, filtering. Running: View → Macros → View Macros → select → Run, or assigned shortcut key, or button on worksheet (Insert → Button → assign macro). Saving: must save as .xlsm (macro-enabled workbook) — .xlsx strips macros. Editing: View → Macros → Edit opens VBA Editor. What is VBA: Visual Basic for Applications — programming language embedded in Excel/Office, enables complex automation beyond what recording captures. VBA Editor (Alt+F11): Project Explorer (lists open workbooks and their modules), Code Window (write/edit code), Properties Window, Immediate Window (test code snippets — Debug.Print). VBA basics: Sub procedures (Sub MacroName() ... End Sub), variables (Dim variableName As DataType — String, Integer, Long, Double, Boolean, Date, Range, Worksheet), message boxes (MsgBox "Hello" — display messages), input boxes (InputBox("Enter value") — get user input), With...End With (apply multiple properties to same object efficiently). Working with ranges: Range("A1").Value = "Hello", Range("A1:D10").Select, ActiveCell, Cells(row, col), Selection, Range("A1").Copy Destination:=Range("B1"). Loops: For...Next (For i = 1 To 100 ... Next i), For Each...Next (For Each cell In Range("A1:A100") ... Next cell — iterate through cells), Do While...Loop. Conditionals: If...Then...Else...End If, Select Case. Practical macro examples: format report with standard colors/fonts/borders (one-click formatting), clean imported data (remove blanks, standardize text, format dates), auto-generate monthly summary from daily sheets, protect/unprotect all sheets at once, auto-email report as PDF. Macro security: Enable/disable macros (File → Options → Trust Center → Trust Center Settings → Macro Settings), trusted locations, digital signatures, security risks (malware can use VBA — never enable macros from untrusted sources). Healthcare VBA automation: monthly coding productivity report (pull data, calculate metrics, format, create charts), auto-format discharge data for state reporting, batch process admission files, auto-populate templates with patient data (de-identified for research)
    - Cover: Macro recording workflow (Record → Perform → Stop → Run), VBA Editor interface anatomy, basic VBA code structure, macro security settings hierarchy
