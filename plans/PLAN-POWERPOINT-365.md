## Lesson Plan (20 Lessons)

### Unit 1: PowerPoint Foundations (L1-4)
1. **"The PowerPoint Environment & Presentation Design Thinking"** — What is PowerPoint: presentation software for creating visual slide decks, part of Microsoft 365. Beyond bullet points: PowerPoint is a VISUAL COMMUNICATION tool, not a document reader. The problem with "Death by PowerPoint": too much text, reading slides verbatim, no visual hierarchy, no story. Presentation design principles: Garr Reynolds (Presentation Zen) — simplicity, restraint, naturalness; Nancy Duarte — contrast, story structure, audience-first design; Edward Tufte — data-ink ratio, avoid chartjunk, small multiples. The 10-20-30 rule (Guy Kawasaki): 10 slides, 20 minutes, 30pt minimum font — guideline not law, but principle of restraint. Cognitive load theory: working memory holds ~4 chunks, slides should SUPPORT speech not replace it, dual coding (words + images processed through different channels = better retention). The PowerPoint interface: Title Bar, Ribbon (Home, Insert, Design, Transitions, Animations, Slide Show, Record, Review, View), Slide pane (main editing area), Slide panel/thumbnail pane (left — navigate, reorder), Notes pane (bottom — speaker notes), Status Bar (slide number, view buttons, zoom). Views: Normal (default editing — slide + thumbnails + notes), Outline (text outline of all slides — great for structuring content), Slide Sorter (all slides as thumbnails — reorder, transitions overview), Notes Page (full-page view with slide and notes — for handout design), Reading View (preview without full screen), Slide Show (F5 — full presentation from beginning, Shift+F5 — from current slide). File formats: .pptx (standard), .ppt (legacy), .potx (template), .ppsx (auto-play slide show — opens directly in presentation mode), .pdf (universal sharing), .mp4 (export as video). Healthcare context: presentations to hospital boards, medical staff committees, quality improvement reports, patient education, conference posters, training modules, accreditation survey preparation
   - Cover: Presentation design principles diagram (simplicity/contrast/story), PowerPoint interface anatomy, cognitive load concept (text + image = dual coding), view comparison grid

2. **"Creating Presentations & Working with Slides"** — Starting: File → New → Blank Presentation or choose template (search: healthcare, medical, education, business). Slide layouts: Title Slide (first slide — presentation title + subtitle), Title and Content (heading + content placeholder — MOST USED), Section Header (divides presentation into sections), Two Content (side-by-side — comparison, image + text), Comparison (two content areas with separate headers), Title Only (heading + blank for custom content), Blank (completely empty — for custom designs), Content with Caption (small text + large content area). Content placeholders: click to add text, or click icons for: table, chart, SmartArt, 3D model, picture, online picture, video. Adding slides: Home → New Slide (dropdown shows all layouts), Ctrl+M (new slide with same layout), right-click in thumbnail pane → New Slide, duplicate slide (Ctrl+D — copies current slide with all content). Slide management: reorder (drag in thumbnail pane or Slide Sorter), delete (select + Delete), hide (right-click → Hide Slide — skip during presentation but keep for reference), sections (right-click between slides → Add Section — organize large presentations: Introduction, Background, Data, Recommendations, Q&A). Content entry: click placeholder → type, bullet levels (Tab = demote/indent, Shift+Tab = promote/outdent), Enter = new bullet, Ctrl+Enter = new text box or move to next placeholder. Reusing slides: Home → New Slide → Reuse Slides — insert slides from another presentation (keep or discard source formatting). Slide size: Design → Slide Size — Standard (4:3, older projectors), Widescreen (16:9, modern default, HD displays), Custom (specific dimensions — poster size for conference posters). Healthcare slide creation: board presentation (15-20 slides: executive summary → background → data → analysis → recommendations → next steps → appendix), quality committee report (dashboard slides → drill-down → action items), patient education (simple, visual, large font, limited text)
   - Cover: Slide layout gallery with use cases, content placeholder icons explained, slide management techniques, presentation structure template (healthcare board report)

3. **"Text Formatting & Typography"** — Text in PowerPoint: text boxes (placeholders or manually inserted), every text element is in a text box. Character formatting: Font (Calibri, Arial, Aptos — sans-serif preferred for presentations over serif), Size (24pt minimum body, 28-36pt recommended, 44pt+ for titles — audience must read from back of room), Bold/Italic/Underline, Font Color (theme colors for consistency), Text Shadow, Character Spacing (expanded for titles, condensed for tight spaces), WordArt Styles (fill, outline, effects — use sparingly). Paragraph formatting: alignment (Left, Center — most common for titles, Right, Justify — avoid in presentations, causes uneven spacing), line spacing (1.0, 1.5, 2.0, custom), spacing before/after paragraphs, bullets (customize symbol, size, color, indent), numbered lists (restart/continue numbering). Text box formatting: Shape Format tab — fill (solid, gradient, picture, pattern, texture, no fill), outline (color, weight, dash style), effects (shadow, reflection, glow, soft edges, 3D), size (exact dimensions), position (exact placement), internal margins (padding inside text box), text alignment (top, middle, bottom — vertical alignment within text box), columns (split text box into 2-3 columns), auto-fit options (shrink text on overflow, resize shape to fit text, do not autofit). Typography best practices for presentations: limit to 2 fonts (one for headings, one for body), maintain consistent hierarchy (same size/weight for same-level elements), avoid ALL CAPS for body text (harder to read, use sparingly for short labels), minimum 24pt for readability, use contrast (dark text on light background or light on dark — never low-contrast like yellow on white), avoid text-heavy slides (6×6 rule guideline: max 6 lines, max 6 words per line — really aim for less). The Takahashi method: one or two words per slide, massive font — extreme simplicity for maximum impact. Healthcare typography: ensure readability for older audience members (board members, physicians), use consistent branding colors/fonts per facility style guide, avoid red/green only (colorblindness — 8% of men), HIPAA — never include PHI in presentations unless absolutely necessary and properly secured
   - Cover: Font size readability guide (distance vs minimum size), text hierarchy example (title/subtitle/body/caption), good vs bad text slide comparison, 6×6 rule visualization

4. **"Working with Color, Themes & Design"** — Color theory basics: primary/secondary/tertiary, warm (red/orange/yellow — energy, urgency) vs cool (blue/green/purple — calm, trust, professionalism), complementary (opposite on color wheel — high contrast), analogous (adjacent — harmonious), monochromatic (one hue, varying lightness — clean, elegant). Color in presentations: background (dark or light — choose one direction), text (high contrast against background), accent colors (for emphasis, highlights, chart colors — 2-3 maximum), brand colors (facility-specific — Pantone/hex values from brand guide). Themes: Design tab → Themes — pre-designed combinations of colors, fonts, and effects. Theme components: Colors (12 color slots: 4 text/background, 6 accent), Fonts (heading + body pair), Effects (shape styling presets — subtle, moderate, intense). Customizing themes: Design → Variants → Colors/Fonts/Effects — change individual components, or create custom: Design → Colors → Customize Colors (name each of 12 color slots), Design → Fonts → Customize Fonts. Slide backgrounds: Design → Format Background — solid fill, gradient (linear, radial, rectangular, path — direction, angle, stops), picture/texture (tile, transparency, offset), pattern fill. Background graphics: Design → Format Background → Hide Background Graphics (removes theme graphics from individual slides for clean custom layouts). Consistent design: Design → Slide Size for aspect ratio, maintain visual consistency across ALL slides (same colors, fonts, placement, margins), use alignment guides (View → Guides, View → Gridlines), Smart Guides (appear automatically when objects align). Design Ideas (Designer): Design → Design Ideas (M365 feature) — AI-powered layout suggestions based on your content, suggests professional layouts for text, images, icons, charts. Healthcare design: facility branding (logo, colors, fonts on every presentation), department color-coding (surgery = blue, cardiology = red, quality = green), professional appearance for external audiences (conferences, accreditation), accessible color choices (sufficient contrast, not relying on color alone, colorblind-safe palettes — blue/orange safe combo)
   - Cover: Color theory wheel with presentation-relevant combos, theme anatomy (colors + fonts + effects), background options comparison, good vs poor color contrast examples

### Unit 2: Visual Content & Multimedia (L5-9)
5. **"Pictures, Icons & Graphics"** — Pictures: Insert → Pictures → This Device / Stock Images / Online Pictures. Picture formatting: Picture Format tab — corrections (brightness, contrast, sharpness), color (saturation, tone, recolor — match brand palette), artistic effects, remove background (automatically detects and removes background — great for product/logo images), crop (standard, crop to shape — circle, hexagon, cloud, star; aspect ratio — 1:1, 16:9, 4:3), size and position. Picture styles: preset frames, borders, effects (shadow, reflection, glow, soft edges, 3D rotation, bevel). Compress pictures: Picture Format → Compress Pictures — reduce file size (email, web, print, high fidelity), apply to all pictures or selected only. Icons: Insert → Icons — thousands of SVG icons in categories (people, technology, healthcare, communication, analytics, education), fully scalable (no pixelation), recolorable (Graphics Format → Graphics Fill), combinable. SVG graphics: scalable vector graphics inserted as pictures, remain sharp at any size, editable (right-click → Convert to Shape for full editing in PowerPoint). Stock images: Insert → Stock Images (M365) — tabs for Images, Icons, Cutout People (transparent background), Stickers, Illustrations, Videos. Screenshot: Insert → Screenshot — capture window or Screen Clipping. Photo album: Insert → Photo Album — create presentation from collection of photos (one or multiple per slide, with captions). Image composition principles: rule of thirds (place focal point at intersection of thirds), use high-quality images (never stretch low-resolution), maintain aspect ratio (lock when resizing), use consistent image style across presentation (all photos, all icons, all illustrations — don't mix styles), white space is your friend (don't fill every pixel). Alt text: right-click → Edit Alt Text — describe image content for accessibility (screen readers for visually impaired audience members). Healthcare visuals: facility photos (campus, equipment, team), medical stock images (avoid generic/cheesy — use authentic clinical photography), icons for data presentation (stethoscope, hospital, chart, shield for security), organizational logos, de-identified clinical images for education (imaging, pathology — remove all PHI), anatomical diagrams
   - Cover: Picture formatting options overview, crop to shape examples, icon recoloring workflow, image composition rule of thirds applied to slides

6. **"Shapes, SmartArt & Diagrams"** — Shapes: Insert → Shapes — categories: lines/connectors (straight, elbow, curved, freeform, arrows), rectangles (square, rounded, snip/fold corner), basic shapes (oval, triangle, diamond, cross, heart, lightning bolt, pentagon, hexagon), block arrows, equation shapes, flowchart symbols (process, decision, terminator, document, data, predefined process), stars/banners, callouts (rectangular, rounded, oval, cloud, line callouts). Shape formatting: Shape Format tab → Shape Fill (solid, gradient, picture, texture, pattern), Shape Outline (color, weight, dash), Shape Effects (shadow, reflection, glow, soft edges, bevel, 3D rotation), Shape Styles (presets). Drawing: freeform shape (draw custom shape point by point), Scribble (freehand drawing), Edit Points (right-click shape → Edit Points — modify vertices for custom shapes). Grouping: select multiple objects → Shape Format → Group — treat as one unit (move, resize, rotate together), Ungroup to edit individually. Arrange: Shape Format → Arrange — Bring Forward/Send Backward (layer order), Align (left, center, right, top, middle, bottom, distribute horizontally/vertically — ESSENTIAL for professional alignment), Rotate (90°, flip horizontal/vertical, free rotate), Selection Pane (View → Selection Pane — list all objects, show/hide, reorder layers, rename for clarity). SmartArt: Insert → SmartArt — pre-designed diagrams. Categories: List (vertical, horizontal, picture lists — bullet point alternatives), Process (basic, chevron, circular arrows, gears — workflows, timelines), Cycle (basic, text, diverging/converging — continuous processes, PDCA), Hierarchy (organization chart, horizontal hierarchy, table hierarchy — org structures, taxonomies), Relationship (Venn, radial, nested, balance — showing connections), Matrix (basic, titled, cycle — quadrant analysis), Pyramid (basic, inverted — hierarchical proportions), Picture (picture accent, snapshot, framed — photo layouts). SmartArt editing: add/remove shapes (SmartArt Design → Add Shape), text pane (type list → auto-generates diagram), change layout (SmartArt Design → Layouts — switch between designs without losing content), colors (SmartArt Design → Change Colors — colorful, monochrome, accent), styles (SmartArt Design → SmartArt Styles — 3D, polished, inset). Converting: text to SmartArt (select text → Home → Convert to SmartArt), SmartArt to shapes (right-click → Convert to Shapes — edit individual shapes). Healthcare diagrams: organizational charts (hospital administration → departments → units), process flowcharts (patient admission workflow, claims processing, coding workflow, ROI process), PDCA cycle (SmartArt cycle), Venn diagrams (overlapping responsibilities: HIM + IT + Compliance), hierarchy (ICD-10 chapter structure), relationship diagrams (stakeholder maps), timeline (EHR implementation phases)
   - Cover: Shape category overview, SmartArt category examples with healthcare applications, alignment and distribute tools, organizational chart example

7. **"Tables & Charts in Presentations"** — Tables: Insert → Table → drag grid or Insert Table dialog. When to use tables in presentations: comparing features/categories side by side, showing structured data (small data sets — NOT large spreadsheets), reference information, schedules, matrices. Table formatting: Table Design tab → Table Styles (themed styles matching presentation design), Table Style Options (Header Row, Total Row, Banded Rows, First Column, Last Column), borders and shading, cell size (distribute evenly), merge/split cells. Table best practices for presentations: keep it simple (max 5-6 rows, 4-5 columns visible), increase font size (minimum 18pt in tables), use alternating row colors for readability, bold headers, minimize borders (clean look — remove internal borders, keep subtle horizontal lines), highlight key cells with color. Charts: Insert → Chart — creates Excel worksheet alongside PowerPoint for data entry. Chart types for presentations: Column/Bar (comparison — "which department has highest volume?"), Line (trends — "how have readmissions changed over 12 months?"), Pie/Doughnut (composition — "what is our payer mix?" — max 5-6 slices), Area (cumulative trends), Scatter (correlation), Combo (line + column — trend + comparison), Funnel (stages — "claims submitted → processed → paid"), Waterfall (build-up/breakdown — "revenue → deductions → net"). Chart formatting: Chart Design tab (styles, color, layout, switch row/column, select data, change chart type), Format tab (shape fill/outline/effects for individual elements). Chart best practices for presentations: one key message per chart (don't overload), clear title that states the insight (not "Revenue Chart" but "Revenue Increased 15% in Q3"), minimize gridlines, label data directly (avoid legend when possible — place labels on/near data), use brand/theme colors, animate chart elements for progressive disclosure. Linking Excel charts: copy chart in Excel → Paste Special in PowerPoint → Paste Link — chart updates when Excel data changes, or embed (independent copy). Healthcare charts: monthly admission trends (line), department comparison (horizontal bar), payer mix (doughnut), quality dashboard metrics (combo), DRG case volume top 10 (bar), readmission rate over time with target line (combo), patient satisfaction scores (bar with benchmark line)
   - Cover: Table design for presentations (clean vs cluttered comparison), chart type selection guide for healthcare data, chart best practices (good vs bad example), linked vs embedded Excel chart concept

8. **"Animations & Transitions"** — Transitions: visual effects when moving BETWEEN slides (applied to slide entry). Applying: Transitions tab → select effect per slide. Categories: Subtle (fade, push, wipe, split, reveal — RECOMMENDED for professional), Exciting (morph, zoom, vortex, shred, fracture — use very sparingly), Dynamic Content (pan, ferris wheel, conveyor). Transition settings: Effect Options (direction — from left, from right, fade through black, etc.), Duration (speed — 0.5-1.5 seconds recommended, not too slow), Sound (rarely appropriate — avoid in professional settings), Advance Slide (on mouse click, after X seconds, or both — auto-advance for kiosk). Apply to All: button to apply same transition to entire presentation — consistency. Morph transition: powerful special transition (available in M365) — smoothly animates objects between two slides (move, resize, rotate, change color), requires same objects on both slides with matching names, great for: zooming into detail, moving elements across screen, shape morphing, smooth layout changes. Animations: visual effects on OBJECTS within a slide (text boxes, images, charts, SmartArt). Categories: Entrance (Appear, Fade, Fly In, Zoom, Bounce, Float — object comes onto slide), Emphasis (Pulse, Spin, Grow/Shrink, Color Change, Bold Flash — draw attention to object already on slide), Exit (Disappear, Fade, Fly Out, Shrink — object leaves slide), Motion Paths (Lines, Arcs, Custom Path — object moves along defined path). Animation Pane: Animations → Animation Pane — timeline of all animations on slide, reorder, adjust timing, modify triggers. Timing: Start (On Click = manual, With Previous = simultaneous, After Previous = sequential), Duration (speed of animation), Delay (pause before starting). Effect Options: direction (from left, from top, etc.), sequence (as one object, by paragraph, by word, by letter — text can reveal bullet by bullet). Multiple animations on one object: Animations → Add Animation (don't click main gallery which replaces) — e.g., Fly In + then Pulse for emphasis + then Fly Out. Triggers: Animations → Trigger → On Click of → specific object — click a button/image to trigger animation. Chart animation: animate by series, category, or element — progressively reveal data (build the story). SmartArt animation: animate by one-by-one or all at once — reveal process steps sequentially. Animation best practices: less is more (animation should serve the MESSAGE not distract), consistent timing (don't mix fast and slow randomly), purposeful use (progressive disclosure of complex information, directing attention, showing sequence/process), avoid bouncing/spinning/sound effects in professional settings. Healthcare animation: reveal quality metrics one at a time (build the narrative), progressively disclose improvement data (before → intervention → after), animate process flowcharts step by step (patient flow, revenue cycle), morph for zooming into dashboard detail
   - Cover: Transition categories with recommended use, animation types (entrance/emphasis/exit/motion path), Animation Pane timeline concept, professional vs distracting animation comparison

9. **"Audio, Video & Multimedia"** — Video: Insert → Video → This Device (local files) or Online Video (embed from YouTube/Vimeo — requires internet during presentation). Video formats: .mp4 (recommended, universal), .wmv (Windows), .mov (Mac). Video formatting: Video Format tab — corrections, color, poster frame (the thumbnail image shown before playing), shape (crop video to shape), border, effects. Playback tab: Start (In Click Sequence, Automatically, When Clicked On), Play Full Screen, Hide While Not Playing, Loop until Stopped, Rewind After Playing, Trim Video (set start/end points without editing original), fade in/out duration, bookmarks (mark specific points in video to jump to). Embedded vs linked: embedded (video stored inside .pptx — larger file but portable, no external dependency), linked (references external file — smaller .pptx but must keep video file with presentation). Audio: Insert → Audio → Audio on My PC or Record Audio. Audio formats: .mp3, .m4a, .wav. Audio playback: Start (Automatically, When Clicked On, In Click Sequence), Play Across Slides (background music), Loop Until Stopped, Hide During Show (for background audio). Record Audio: Insert → Audio → Record Audio — narrate explanations, add voice-over. Screen Recording: Insert → Screen Recording — capture screen activity with audio narration (record software demonstrations, EHR workflow walkthroughs), saved as embedded video, trimable. Record Slide Show: Slide Show → Record — records narration, ink annotations, laser pointer, slide timings for each slide — creates self-running narrated presentation. Export as video: File → Export → Create a Video — choose quality (Ultra HD 4K, Full HD 1080p, HD 720p, Standard 480p), use recorded timings/narrations, output as .mp4 — for sharing as video file, uploading to LMS, posting online. Multimedia best practices: test audio/video BEFORE presenting (different computer may lack codecs), keep videos short (2-3 minutes max per clip in a live presentation), ensure audio quality (external microphone for recording), provide captions/subtitles for accessibility, check copyright (fair use, Creative Commons, licensed content). Healthcare multimedia: patient education videos embedded in presentations, recorded training modules (screen recording of EHR workflows for new employee orientation), narrated self-paced learning modules (record slide show for compliance training), conference poster presentations with embedded video demonstrations, kiosk presentations for waiting rooms (auto-advance, loop, no sound or low background music)
   - Cover: Video insertion and playback options, screen recording workflow, Record Slide Show concept, export as video settings

### Unit 3: Advanced Design & Features (L10-14)
10. **"Slide Master: Controlling Presentation Design"** — What is Slide Master: the top-level slide in the slide hierarchy that controls formatting for ALL slides — change once, updates everywhere. Accessing: View → Slide Master. Slide Master hierarchy: Slide Master (top — affects ALL layouts, contains: background, theme colors/fonts, logo placement, footer areas, placeholder positions) → Layout Masters (individual layouts — Title Slide, Title and Content, Two Content, etc. — each inherits from Slide Master but can be customized independently). Editing Slide Master: change font (all text across all slides updates), add logo (appears on every slide), modify background, adjust placeholder size/position, add/remove footer areas, apply theme colors. Editing Layout Masters: customize individual layouts — move placeholders, change default formatting, add layout-specific elements. Creating custom layouts: Slide Master → Insert Layout → add placeholders (Content, Text, Picture, Chart, Table, SmartArt, Media, Online Image), name the layout, close Slide Master View — custom layout appears in New Slide dropdown. Placeholder types: Title, Content (versatile — text, table, chart, SmartArt, pictures, video), Text (text only), Picture, Chart, Table, SmartArt, Media, Online Image. Multiple Slide Masters: one presentation can have multiple Slide Masters (Insert → Slide Master in Slide Master View) — useful for: different sections with different branding (merged organizations), bilingual presentations, different background for title vs content sections. Preserving: Slide Master → Preserve — prevents deletion even when no slides use it. Footer areas: Insert → Header and Footer → date/time (auto-update or fixed), slide number, footer text, "Don't show on title slide" option — controlled in Slide Master. Healthcare Slide Master: facility Slide Master with logo top-right, facility name in footer, department color accent bar, consistent font pairing (Calibri headings + body), custom layouts for: data dashboard slide, before/after comparison, policy summary, team roster
   - Cover: Slide Master hierarchy diagram (Master → Layouts → Slides), editing Slide Master vs Layout Master, custom layout creation, healthcare branded Slide Master example

11. **"Templates & Reusable Presentations"** — Templates vs Themes: theme = colors + fonts + effects (Design tab → Themes), template = theme + custom layouts + default content + Slide Master configurations + sample slides (.potx file). Creating templates: design Slide Master → create custom layouts → add sample slides with placeholder text/instructions → File → Save As → PowerPoint Template (.potx) → saves to Custom Office Templates. Using templates: File → New → Personal/Custom → select template → creates new presentation based on template. Organizational templates: share via: network drive (\\server\templates\), SharePoint (template library), email, Teams channel file tab. When to use: recurring presentations (monthly board report, quarterly quality review), facility branding consistency (all departments use same branded template), training standardization. Template components to include: branded Slide Master (logo, colors, fonts), title slide layout, section divider layout, content layouts (text + image, data dashboard, comparison, process), thank you / Q&A slide, speaker notes with presentation tips, sample slides showing how to use each layout. Content templates vs design templates: design template (visual look only — colors, fonts, backgrounds, layouts), content template (design + pre-built slide structure — monthly report template with specific slides for each section, just fill in new data). Quick Styles: save custom formatting as quick styles for shapes, text boxes, chart elements — reusable within presentation. Default shape/text formatting: right-click formatted shape → Set as Default Shape — all new shapes use this formatting, right-click formatted text → Set as Default Text Box. Healthcare templates: monthly quality dashboard template (12 pre-built slides: cover, executive summary, 8 metric slides with chart placeholders, action items, appendix), committee meeting template (agenda, minutes structure, action items, next steps), patient education template (simple layouts, large fonts, image-heavy, plain language), conference poster template (standard sizes: 36"×48", 42"×60", research poster layout with sections), new employee orientation template (facility branding, standard content structure)
    - Cover: Template creation workflow, template vs theme comparison, organizational template distribution, healthcare template library examples

12. **"Advanced Formatting & Professional Polish"** — Alignment and distribution: Home → Arrange → Align — align objects to each other or to slide. Align Left/Center/Right/Top/Middle/Bottom — at least 2 objects selected. Distribute Horizontally/Vertically — even spacing between 3+ objects. Align to Slide vs Align Selected Objects — toggle in Align menu. Grid and guides: View → Gridlines (snap-to grid for consistent spacing), View → Guides (draggable reference lines — set consistent margins, alignment zones), smart guides (appear automatically when objects align with each other or slide center). Rulers: View → Ruler — shows measurements, drag indent markers for text formatting. Selection Pane: View → Selection Pane — list every object on slide by name, show/hide (eye icon), reorder layers (drag up/down), rename objects (double-click name — critical for Morph transitions, accessibility), lock objects. Merge Shapes: Shape Format → Merge Shapes — Union (combine into one), Combine (remove overlap), Fragment (split at intersections), Intersect (keep only overlap), Subtract (cut one shape from another) — create custom shapes. Custom colors: eyedropper tool (Shape Fill → Eyedropper — pick exact color from any image on slide — match photo colors, brand colors from logo). Transparency: shape fill transparency slider (create overlays, watermarks), image transparency (Insert → Pictures → Format → Transparency). Background removal: Picture Format → Remove Background — mark areas to keep/remove, refine edge. Crop to shape: Picture Format → Crop → Crop to Shape — circle headshots, hexagon grids. Slide zoom: Insert → Zoom — Summary Zoom (creates overview slide linking to sections), Section Zoom (link to specific section from any slide), Slide Zoom (link to specific slide) — non-linear navigation, great for Q&A or choose-your-path presentations. Design Ideas (Designer): Home → Design Ideas or Design tab → Design Ideas — AI suggests professional layouts based on content (M365 feature). Healthcare polish: consistent margins on every slide (use guides at 0.5" from edges), align all objects to grid, name objects in Selection Pane for complex slides, use merge shapes for custom infographic elements, eyedropper to match exact facility brand colors from logo
    - Cover: Alignment and distribution tools visual guide, merge shapes operations with examples, Selection Pane management, Slide Zoom navigation concept

13. **"Data Visualization in Presentations"** — Presenting data effectively: slides are NOT spreadsheets — show the INSIGHT, not the raw data, use charts to tell a story. Chart selection for presentations: comparison (bar/column — horizontal bar when labels are long), trend (line — time series), composition (pie/doughnut — max 5 slices, use doughnut for percentage in center trick), distribution (histogram, box plot), relationship (scatter, bubble), part-to-whole over time (stacked area/bar), ranking (horizontal bar sorted), flow (waterfall, funnel). Chart design for projection: larger fonts (axis labels, data labels minimum 14pt), thicker lines (2-3pt for line charts), high-contrast colors (visible from back of room, projector washes out subtle colors), remove clutter (minimize gridlines, remove unnecessary legends, label data directly), one message per chart (title states the insight: "Readmissions Dropped 23% After Intervention" not "Readmission Data"). Progressive disclosure with animation: animate chart by series or category — reveal one data set at a time, build the comparison/narrative (show baseline → then show improvement → then show target). Dashboard slides: multiple small charts on one slide (overview), follow with detail slides for each metric, use consistent chart types and colors across dashboard elements. Infographic-style data: icons + numbers (large stat with icon: "🏥 4,200 Discharges"), comparison blocks, pictograms (icon arrays — each icon = 100 patients), progress bars (shapes + percentage). Tables for data: when to use table vs chart (table for exact values, chart for patterns/comparisons), keep tables minimal in presentations (max 6×6), alternate row shading, large font, bold headers. KPI scorecards: single-number displays with context (current value, trend arrow ↑↓, comparison to target/benchmark, RAG color coding — red/amber/green), build with shapes and text boxes. Sparklines: no built-in sparkline in PowerPoint, but create with: tiny embedded Excel chart, or draw with shapes/lines, or screenshot from Excel. Healthcare data visualization: quality scorecards (mortality, readmissions, HAIs, patient satisfaction — each as KPI card), monthly trend dashboards, payer mix doughnut, department comparison bars, before-and-after improvement data, benchmarking (facility vs peer group vs national), accreditation survey readiness scores
    - Cover: Chart type selection for presentations, dashboard slide layout, KPI scorecard design, progressive disclosure animation for charts

14. **"Accessibility & Inclusive Design"** — Why accessibility matters: legal (ADA, Section 508, WCAG 2.1 — federal agencies and many healthcare organizations must comply), ethical (estimated 1 in 4 adults has a disability, presentations should be usable by all), practical (accessibility features improve usability for EVERYONE — good contrast, clear structure, readable fonts). Accessibility Checker: Review → Check Accessibility — scans for issues, provides warnings and tips, fix suggestions. Common issues and fixes: missing alt text (right-click → Edit Alt Text — describe image content for screen readers, mark decorative images), reading order (objects read by screen reader in order from Selection Pane — reorder to logical sequence: title first, then content left-to-right, top-to-bottom), slide titles (every slide MUST have a unique title — screen reader uses titles to navigate, even if title is visually hidden: move off-slide or use Title placeholder with tiny font), table structure (set header row, simple structure — avoid merged cells, nested tables), hyperlink text (descriptive — "View HIPAA Policy" not "Click here" or raw URL), color contrast (sufficient contrast ratio — 4.5:1 for body text, 3:1 for large text, use WebAIM contrast checker), don't rely on color alone (add labels, patterns, shapes in addition to color — for colorblind users), meaningful slide order (slides should make sense in order), video/audio (closed captions, transcripts). Reading order: Home → Arrange → Selection Pane — drag objects to correct reading order (bottom of list is read first by screen reader in some versions — verify with screen reader testing). Slide titles: even "decorative" slides need titles for navigation — use Layout with title placeholder, or add off-screen title. Alt text best practices: be concise (1-2 sentences), describe content and purpose ("Bar chart showing readmission rates declining from 15% to 11% over 6 months"), don't start with "Image of..." (screen reader already says "image"), mark purely decorative images as decorative (empty alt text). Color and fonts: sans-serif fonts (easier to read — Calibri, Arial, Verdana, Aptos), minimum 24pt body text, high contrast (dark text on light or light on dark), avoid red/green only distinctions, avoid patterned backgrounds behind text. Accessible templates: build accessibility into templates (proper reading order, title placeholders, high-contrast theme, alt text reminders) — easier to prevent issues than fix them. Healthcare accessibility: patient education materials MUST be accessible (diverse patient populations, varying abilities), training presentations for employees with disabilities, compliance with facility accessibility policies, Joint Commission requires patient communication accommodations
    - Cover: Accessibility Checker panel walkthrough, reading order setup, color contrast do's and don'ts, alt text writing guide

### Unit 4: Presenting & Collaboration (L15-18)
15. **"Delivering Presentations: Slide Show & Presenter Tools"** — Starting slide show: F5 (from beginning), Shift+F5 (from current slide), Slide Show tab → From Beginning / From Current Slide. Presenter View: Slide Show → Use Presenter View — dual-screen setup (audience sees slide, presenter sees: current slide, next slide preview, speaker notes, timer/clock, slide navigation, tools). Presenter View tools: pen/highlighter/laser pointer (draw on slides during presentation — ink annotations, emphasize points), eraser, zoom (magnify part of slide), black/white screen (B key = black screen for breaks/discussion, W key = white screen), all slides grid (jump to any slide). Slide Show navigation: arrow keys / click (next slide), Backspace / right-click → Previous (previous), number + Enter (jump to specific slide — type "12" + Enter for slide 12), Esc or right-click → End Show (end presentation), Home (first slide), End (last slide). Custom Slide Show: Slide Show → Custom Slide Show — create named subsets of slides (e.g., "Board Version" = slides 1-5,8,12-15, "Staff Version" = slides 1-15,20-25) — tailor one presentation for different audiences without duplicating files. Hide slides: right-click slide → Hide Slide — skipped during normal presentation but accessible via right-click → Go to Slide during show. Set Up Show: Slide Show tab → Set Up Slide Show — Presented by speaker (full screen, manual), Browsed by individual (window, self-paced), Browsed at kiosk (full screen, auto-loop). Laser pointer: Ctrl+L during presentation turns cursor into laser pointer (red dot), Ctrl+P for pen, Ctrl+I for highlighter, Ctrl+M to hide pointer. Speaker notes: Notes pane below slide — type notes for presenter reference, visible in Presenter View, printable as notes pages. Rehearse Timings: Slide Show → Rehearse Timings — practice with timer, saves timings per slide for auto-advance. Live Captions & Subtitles: Slide Show → Always Use Subtitles (M365) — real-time speech-to-text captions during presentation, supports multiple languages, improves accessibility. Healthcare presenting: board presentations (Presenter View essential — notes + audience control), training sessions (pen for annotation, laser for emphasis), grand rounds (custom slide show for different topics from same deck), kiosk mode for patient education in waiting rooms
    - Cover: Presenter View layout diagram, slide show navigation shortcuts, Custom Slide Show concept, live captions accessibility feature

16. **"Printing, Handouts & Sharing"** — Printing: Ctrl+P — print options: Full Page Slides (one slide per page), Notes Pages (slide + speaker notes — great for presenter copy), Outline (text outline only), Handouts (1, 2, 3, 4, 6, or 9 slides per page — 3 per page includes lined note area). Print settings: color (Color, Grayscale, Pure Black and White), frame slides (thin border around each slide — better definition on white paper), header/footer on handouts (Insert → Header and Footer → Notes and Handouts tab). Exporting: File → Export → Create PDF/XPS (preserves formatting, universal sharing, handout layout options), Create a Video (.mp4 — quality options, use recorded timings or set default seconds per slide, narration included if recorded), Create Handouts in Word (send slides to Word document — outlines next to slides, blank lines next to slides, notes below slides — fully editable in Word), Package Presentation for CD (copies .pptx + linked files + viewer into folder/disc — for offline sharing). Sharing: File → Share → OneDrive (co-authoring — multiple editors, comment/review), email as attachment (.pptx or .pdf), share link (edit or view-only). Saving for compatibility: File → Save As → PowerPoint 97-2003 (.ppt) for older systems, PDF for universal viewing, PPSX for auto-play (opens directly in slide show mode). Compressing file size: Picture Format → Compress Pictures (reduce resolution), File → Info → Compress Media (compress embedded videos), delete unused Slide Masters, remove cropped areas from pictures. Presentation packaging: for external events — save as .ppsx (auto-play), embed all fonts (File → Options → Save → Embed fonts in the file), embed/include all media, test on the presentation computer before going live. Healthcare handouts: committee meeting handouts (3 slides per page with notes lines), training handout packets, board presentation PDF (email before meeting for pre-reading), patient education slides printed as handouts (large layout — 1-2 per page), conference poster PDF for printing at poster size
    - Cover: Print layout options comparison (full page/notes/handouts), export options and when to use each, file compression techniques, sharing method comparison

17. **"Collaboration & Review"** — Comments: Review → New Comment — add feedback to specific slides/objects, threaded replies, @mention collaborators (they receive notification), resolve comments (mark as done without deleting), filter by reviewer. Compare: Review → Compare — merge changes from another version of the presentation (reviewer works on copy → compare back to original), accept/reject changes per slide. Co-authoring: requires OneDrive/SharePoint save, multiple editors simultaneously, colored presence indicators showing who's editing which slide, real-time sync, AutoSave, works in desktop app and web app. Version History: File → Info → Version History — browse all auto-saved versions, restore previous version, compare versions side-by-side. Protect Presentation: File → Info → Protect Presentation — Mark as Final (read-only suggestion, easily bypassed), Encrypt with Password (requires password to open), Restrict Access (IRM — Information Rights Management, control who can edit/copy/print, requires Azure RMS), Add Digital Signature (verify integrity and authenticity). Restrict Editing: no direct restrict editing in PowerPoint like Word — use: protect presentation password, share as view-only link, convert to PDF for review, share .ppsx for presentation-only. Section-based collaboration: assign presentation sections to different team members, each works on their section, combine in master file. Review workflow: draft → share for review → collect comments → revise → final review → approve → distribute. PowerPoint for the web: Office.com → PowerPoint — browser-based editing, subset of desktop features, great for quick edits and collaboration, automatic save to OneDrive/SharePoint, real-time co-authoring. Teams integration: share PowerPoint in Teams meeting (Present in Teams button, PowerPoint Live — attendees see their own view, can browse slides independently, private notes, accessibility features: screen reader, high contrast), upload to Teams channel Files tab, collaborate in Teams. Healthcare collaboration: quality committee presentations (multiple departments contribute sections), accreditation preparation (distribute sections, combine, review), training module development (instructional designer + subject matter expert), board presentation review cycle (draft → department head review → CFO/CMO review → CEO approval → board)
    - Cover: Comment and review workflow, co-authoring with presence indicators, version history timeline, PowerPoint Live in Teams features

18. **"Advanced Techniques & Special Presentation Types"** — Section Zoom & Summary Zoom: Insert → Zoom — create non-linear navigation. Summary Zoom: automatically creates overview slide with thumbnails linking to each section — click to zoom into section, return to overview after section ends. Section Zoom: insert link to any section from any slide. Slide Zoom: link to a specific slide. Use for: choose-your-own-adventure style, Q&A (jump to relevant section), executive summary with drill-down capability. Morph transition mastery: name objects identically on consecutive slides (e.g., "!!Circle1") → Morph smoothly animates position, size, rotation, color changes between slides. Advanced morph: morph shapes into other shapes (circle → square), morph text (individual characters animate), morph for zoom effect (small element on slide 1 → large on slide 2), morph for reveal (objects move to reveal content underneath). Custom shows within presentations: Slide Show → Custom Slide Show — multiple named shows from one file, great for: different audiences (board 10-min version, staff 30-min version), modular training (core + elective modules). Interactive presentations: hyperlinks on shapes (click shape → jump to slide, URL, file), action buttons (Insert → Shapes → Action Buttons — forward, back, home, custom), triggers (animation starts when specific object is clicked). Kiosk/self-running: Slide Show → Set Up Show → Browsed at a Kiosk, auto-advance with timings, loop continuously. Narrated/recorded presentations: Slide Show → Record → record narration + camera + annotations per slide → export as video or share as self-paced presentation. Poster presentations: Design → Slide Size → Custom (36"×48" or 42"×60"), single-slide poster with sections (title, introduction, methods, results, discussion, conclusion, references), high-resolution images, readable from 4 feet. Photo slideshows: Insert → Photo Album — create photo-based presentations with layouts and transitions. Healthcare special types: interactive training module (branching scenarios — click correct answer → advance, click wrong → remediation slide), kiosk patient education (waiting room loop), narrated compliance training (record once, distribute via LMS), conference research poster (single slide, printed large-format), board dashboard presentation (Summary Zoom for section navigation)
    - Cover: Summary Zoom navigation concept, Morph transition examples, interactive branching scenario flow, conference poster layout template
