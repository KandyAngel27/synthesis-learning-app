## Lesson Plan (22 Lessons)

### Unit 1: Word Foundations (L1-4)
1. **"The Word Environment & Interface"** — What is Word: professional document creation application, part of Microsoft 365, THE standard for business/healthcare documents (policies, procedures, reports, correspondence, manuals, forms). Word vs Google Docs vs LibreOffice Writer — when to use each (Word dominates enterprise/healthcare, Google Docs for real-time collaboration, Writer for free/open-source). The Word interface: Title Bar (file name, AutoSave for OneDrive/SharePoint), Ribbon (tabs: Home, Insert, Design, Layout, References, Mailings, Review, View — contextual tabs appear when objects selected), Quick Access Toolbar (customize — Save, Undo, Redo), Ruler (horizontal + vertical — margins, indents, tab stops, drag to adjust), Status Bar (page count, word count, proofing, view buttons, zoom slider), Navigation Pane (View → Navigation Pane or Ctrl+F — headings outline, page thumbnails, search). Document views: Print Layout (default — WYSIWYG, shows page breaks, margins, headers/footers), Read Mode (optimized for reading, no editing distractions), Web Layout (no page breaks, how it would look as web page), Outline (document structure by heading levels, reorganize by dragging), Draft (fast editing, no graphics/headers displayed, shows section breaks). Zoom: Ctrl+scroll wheel, View → Zoom, or zoom slider on status bar. File formats: .docx (standard, XML-based), .doc (legacy, pre-2007), .dotx (template), .dotm (macro-enabled template), .pdf (universal sharing format), .rtf (rich text, cross-platform compatibility), .txt (plain text, no formatting). Keyboard essentials: Ctrl+S (save), Ctrl+Z/Y (undo/redo), Ctrl+A (select all), Ctrl+Home/End (beginning/end of document), Ctrl+Enter (page break), Ctrl+Shift+Enter (column break), F1 (help), Shift+F3 (toggle case — UPPER/lower/Title)
   - Cover: Word interface anatomy diagram (Ribbon/Ruler/Navigation Pane/Status Bar labeled), document view comparison, file format comparison table, essential keyboard shortcuts card

2. **"Text Entry, Selection & Basic Editing"** — Document creation: File → New → Blank document (Ctrl+N), or from template. Typing fundamentals: word wrap (text automatically flows to next line — do NOT press Enter at end of each line, only at end of paragraphs), AutoCorrect (fixes common typos automatically — teh→the, capitalize first letter of sentences, customize: File → Options → Proofing → AutoCorrect Options), AutoText / Quick Parts (save frequently used text blocks — Insert → Quick Parts → AutoText, or type abbreviation + F3). Selection techniques: click (place cursor), double-click (select word), triple-click (select paragraph), click beginning + Shift+click end (select range), Ctrl+click (select sentence), Ctrl+A (select all), click in left margin (select line), double-click margin (select paragraph), Ctrl+Shift+arrow (select word by word), Shift+End (select to end of line), vertical/block selection (Alt+click+drag — select a column of text). Editing: Cut (Ctrl+X), Copy (Ctrl+C), Paste (Ctrl+V), Paste Special (Ctrl+Alt+V — paste as plain text, formatted text, picture, link), Clipboard pane (Home → Clipboard launcher — stores up to 24 copied items), drag-and-drop (select text → drag to new location, Ctrl+drag to copy). Find & Replace: Ctrl+H — find text → replace with new text, options (match case, whole words only, use wildcards — * any characters, ? single character, [a-z] character range), replace formatting (change all instances of one font/style to another), special characters (^p = paragraph mark, ^t = tab, ^l = manual line break, ^n = column break). Undo/Redo: Ctrl+Z unlimited undo (click dropdown arrow to undo multiple actions at once), Ctrl+Y redo. AutoRecover: File → Options → Save — auto-save interval (default 10 min, set to 2-3 min for safety), recover unsaved documents (File → Info → Manage Document → Recover Unsaved). Healthcare text entry: entering patient correspondence, typing policies and procedures, drafting committee minutes, creating educational materials
   - Cover: Selection technique reference (click types mapped to what they select), Find & Replace dialog with wildcards, Clipboard pane concept, AutoRecover settings

3. **"Character Formatting"** — Font basics: Font (typeface — Calibri, Arial, Times New Roman, Aptos), Font Size (points — 12pt standard body, 14-28pt for headings), Bold (Ctrl+B), Italic (Ctrl+I), Underline (Ctrl+U — single, double, dotted, dashed, wavy, color options), Strikethrough, Subscript (Ctrl+=), Superscript (Ctrl+Shift+=). Font Color: theme colors (change with document theme), standard colors, custom colors (RGB, hex), automatic (adapts to background). Text effects: shadow, reflection, glow, outline, text highlight color (like a highlighter pen — great for review markup). Character spacing (Font dialog → Advanced tab): scale (stretch/compress), spacing (expanded/condensed — points between characters), position (raised/lowered), kerning (adjust spacing between specific character pairs for polished look at large sizes). Change Case: Shift+F3 cycles through (lowercase → UPPERCASE → Title Case), or Home → Change Case dropdown (Sentence case, lowercase, UPPERCASE, Capitalize Each Word, tOGGLE cASE). Format Painter: Home → Format Painter (paintbrush icon) — copy formatting from one selection to another, single-click for one-time use, double-click to lock on (apply to multiple selections, Esc to turn off). Clear Formatting: Ctrl+Spacebar (clear character formatting), Ctrl+Q (clear paragraph formatting to style default), Home → Clear All Formatting button (clears everything back to Normal style). Font dialog (Ctrl+D): all character options in one place — font, style, size, color, effects (strikethrough, double strikethrough, superscript, subscript, small caps, all caps, hidden text), Advanced tab (spacing, OpenType features). Mini Toolbar: appears when you select text — quick access to common formatting without going to Ribbon. Healthcare formatting: bold for warnings/alerts in policies, italic for medical terminology definitions, superscript for footnotes/references, specific fonts required by facility style guide (many hospitals mandate Arial or Calibri for consistency)
   - Cover: Character formatting toolbar with each option labeled, character spacing comparison (normal vs expanded vs condensed), Format Painter workflow, Font dialog anatomy

4. **"Paragraph Formatting"** — Paragraph defined in Word: everything between two paragraph marks (¶) — could be one line or many. Show/Hide ¶ marks: Ctrl+Shift+8 or Home → ¶ button — ESSENTIAL for troubleshooting formatting (see invisible characters: spaces, tabs, paragraph marks, section breaks, manual line breaks). Alignment: Left (Ctrl+L, default), Center (Ctrl+E), Right (Ctrl+R), Justify (Ctrl+J — both edges flush, adds space between words). Line spacing: single, 1.15 (default in Word), 1.5, double (Ctrl+2), exact (specific point value), multiple (custom multiplier — 1.08, 2.5), at least (minimum height, expands if needed). Paragraph spacing: Space Before / Space After (points — standard: 0 before, 8 after for body text, eliminates need for blank lines between paragraphs), don't add space between paragraphs of same style option. Indentation: Left indent (entire paragraph moves right), Right indent (entire paragraph moves left), First Line indent (only first line — standard: 0.5", replaces Tab at start of paragraph), Hanging indent (first line stays, rest indent — used for bibliographies, numbered lists, glossaries), adjust via ruler (drag markers) or Layout tab (exact values). Tab stops: Left tab (default, text flows right), Center tab (text centers on tab), Right tab (text flows left — for right-aligning numbers), Decimal tab (aligns on decimal point — ESSENTIAL for financial columns), Bar tab (inserts vertical line). Set tabs: click ruler at desired position (click tab selector on left end of ruler to change type), or Paragraph dialog → Tabs button (exact positions, leaders — dot leader, dash leader, solid line leader — used for table of contents). Borders and shading: Home → Borders dropdown (bottom border, box border, all borders, custom), Borders and Shading dialog (line style, color, width, apply to paragraph or text, padding), shading (background color for paragraph — great for callout boxes, warnings). Paragraph dialog (right-click → Paragraph or Layout tab): all spacing/indentation options, keep with next (prevent heading from being separated from body), keep lines together (prevent paragraph from splitting across pages), page break before (force paragraph to top of new page), widow/orphan control (prevent single lines at top/bottom of page — always on by default). Healthcare paragraph formatting: standard body text (Calibri 11pt, 1.15 spacing, justified), policy format (specific indentation for numbered procedures), hanging indent for reference lists, decimal tabs for financial reports, borders/shading for warning boxes in clinical guidelines
   - Cover: Paragraph mark and invisible characters guide, alignment comparison (left/center/right/justify), indent types illustrated on ruler, tab stop types with examples

### Unit 2: Document Design & Structure (L5-8)
5. **"Styles: The Foundation of Professional Documents"** — What are styles: saved collections of formatting attributes (font, size, color, spacing, indentation, borders) applied with one click. Why styles matter: consistency (every heading looks the same), efficiency (change one style definition → ALL text with that style updates), structure (styles create document outline, enable auto-generated TOC, enable Navigation Pane headings), professionalism (uniform appearance). Built-in styles: Normal (default body text), Heading 1-9 (hierarchical heading levels — most documents use 1-3), Title, Subtitle, Quote, Intense Quote, List Paragraph, No Spacing, Emphasis, Strong. Styles gallery: Home tab → Styles group — shows most-used styles, click to apply, right-click for options. Styles pane: Home → Styles launcher (Ctrl+Alt+Shift+S) — full list, show preview, filter (recommended, in use, in current document, all styles). Applying styles: select text → click style, or place cursor in paragraph → click paragraph style. Modifying styles: right-click style → Modify — change font, size, color, spacing, anything — ALL text with that style updates instantly. Creating new styles: Format → Style → New Style, or format text the way you want → select → Styles gallery → Create a Style. Based on: style inheritance — Heading 2 based on Heading 1 means changes to Heading 1 cascade to Heading 2 (unless overridden). Style for following paragraph: after pressing Enter, automatically switches to the specified style (Heading 1 → Normal, saves time). Managing styles: Manage Styles dialog — set which styles appear in gallery, import/export styles between documents/templates. Multilevel list linked to styles: create automatic numbered headings (1. → 1.1 → 1.1.1) linked to Heading 1/2/3 styles — essential for policies, procedures, regulations. Style Sets: Design tab → Document Formatting — predefined combinations of style definitions (change the entire document's look with one click). Healthcare style system: Policy Title (Heading 1 — 16pt, bold, blue, centered), Section Header (Heading 2 — 14pt, bold, left), Subsection (Heading 3 — 12pt, bold italic), Body (Normal — 11pt, justified, 1.15 spacing), Procedure Step (custom — numbered, indented), Warning/Caution (custom — red border, yellow shading, bold)
   - Cover: Style hierarchy diagram (Title → Heading 1 → Heading 2 → Normal), style modification dialog, multilevel list linked to heading styles, healthcare policy style system example

6. **"Page Layout, Sections & Columns"** — Page Setup: Layout tab → Page Setup group. Margins: Normal (1" all), Narrow (0.5"), Moderate (0.75" top/bottom, 1" sides), Wide (1" top/bottom, 2" sides), Mirrored (for bound documents — inside/outside margins), Custom (set exact values). Orientation: Portrait (vertical, default) vs Landscape (horizontal — for wide tables, charts, timelines). Paper size: Letter (8.5×11", US standard), Legal (8.5×14"), A4 (international), custom sizes. Sections: divide document into independently formatted segments. Section break types: Next Page (new section starts on next page — most common, used when changing orientation or margins mid-document), Continuous (new section on same page — used for column changes), Even Page / Odd Page (new section starts on next even/odd page — for booklet printing). Why sections: different headers/footers per section (cover page with no header, body with header), different page orientation mid-document (portrait for text, landscape for wide table, back to portrait), different margins per section, different column layouts, different page numbering (roman numerals for front matter, arabic for body). Columns: Layout → Columns — One, Two, Three, Left (narrow left + wide right), Right (wide left + narrow right), More Columns (custom widths, spacing, line between). Column break: Ctrl+Shift+Enter — force text to next column. Vertical alignment: Layout → Page Setup → Layout tab — Top (default), Center (vertically center content on page — great for cover pages), Justified (spread evenly), Bottom. Line numbers: Layout → Line Numbers — useful for legal documents, code review, committee markup. Hyphenation: Layout → Hyphenation — Automatic (Word decides), Manual (you approve each), Hyphenation Zone (distance from right margin). Healthcare layout: policy documents (1" margins, portrait, single column for body, two-column for quick-reference cards), patient education materials (larger margins for readability, often two-column), committee meeting minutes (standard layout), landscape section for wide organizational charts or Gantt timelines
   - Cover: Margin presets comparison, section break types with use cases, multi-section document example (cover + portrait body + landscape table + portrait appendix), column layout options

7. **"Tables: Creation, Formatting & Data"** — Creating tables: Insert → Table → drag grid (up to 10×8 visual), Insert Table dialog (exact rows × columns, auto-fit behavior), Draw Table (freehand — draw cells of different sizes), Convert Text to Table (select text with consistent delimiters — tabs, commas, paragraphs → Insert → Table → Convert Text to Table), Quick Tables (pre-designed — calendars, tabular lists, matrix). Table navigation: Tab (next cell), Shift+Tab (previous cell), arrow keys (move within cell text), Tab at last cell (creates new row). Selecting: click inside cell left edge (cell), click left margin next to row (row), hover above column border (column), Alt+5 on numpad with Num Lock off (entire table), or Table Layout tab → Select menu. Inserting/deleting: Table Layout → Insert Above/Below/Left/Right (add rows and columns), Delete → Rows/Columns/Table/Cells. Resizing: drag cell borders, AutoFit (AutoFit Contents — shrink to fit text, AutoFit Window — stretch to page width, Fixed Column Width), distribute rows/columns evenly, exact cell dimensions (Table Layout → Cell Size group). Merging/splitting: select cells → Table Layout → Merge Cells (combine into one — headers spanning multiple columns), Split Cells (divide one cell into multiple). Table formatting: Table Design tab → Table Styles (light, medium, dark themes — one click to format professionally), Table Style Options (Header Row, Total Row, Banded Rows, First Column, Last Column, Banded Columns — toggle to fine-tune style application), borders (Borders dropdown → Borders and Shading for custom), shading (cell background color), cell alignment (9 options: top-left through bottom-right). Text in tables: direction (change text to vertical for narrow columns — Table Layout → Text Direction), cell margins (Table Layout → Cell Margins — add padding), paragraph formatting within cells (all normal paragraph formatting works). Sorting table data: Table Layout → Sort — by any column, ascending/descending, up to 3 sort levels, with/without header row. Formulas in tables: Table Layout → Formula — =SUM(ABOVE), =AVERAGE(LEFT), cell references (A1 format within table), limited but useful for simple totals without Excel. Converting: Table to Text (Table Layout → Convert to Text — choose delimiter), Text to Table (select text → Insert → Table → Convert). Nested tables: table inside a table cell — used for complex layouts. Healthcare tables: medication lists (drug, dose, route, frequency, indication), committee rosters, policy revision history tables, coding reference tables, organizational charts in table format, patient assessment forms
   - Cover: Table creation methods comparison, merge/split concept, table style options toggles, cell alignment 9-option grid

8. **"Graphics, Images & Visual Elements"** — Pictures: Insert → Pictures → This Device (local files), Stock Images (Microsoft library — free with M365), Online Pictures (Bing search). Picture formatting: Picture Format tab → corrections (brightness, contrast, sharpness), color (saturation, tone, recolor — grayscale, sepia, accent colors), artistic effects (blur, paint stroke, pencil sketch), crop (standard, crop to shape, aspect ratio), size (exact dimensions, lock aspect ratio), compress pictures (reduce file size — email, print, web resolution). Text wrapping: how text flows around images — In Line with Text (default, image acts like a character), Square (text wraps in rectangle around image), Tight (text follows image contour), Through (text fills gaps in image), Top and Bottom (text above and below only), Behind Text (image behind text — for watermarks, letterhead), In Front of Text (image on top of text). Position: Layout Options → Position — predefined positions (top left, center, bottom right), or drag manually, anchor (images anchored to paragraph — moves with text). Shapes: Insert → Shapes — lines, arrows, rectangles, ovals, callouts, flowchart symbols, stars, banners, equation shapes. SmartArt: Insert → SmartArt — pre-designed diagrams: List (bullet alternatives), Process (flowcharts, step sequences), Cycle (continuous processes), Hierarchy (org charts), Relationship (Venn diagrams, overlapping concepts), Matrix (quadrant grids), Pyramid (hierarchical proportions), Picture (image layouts). SmartArt formatting: add/remove shapes, change layout, SmartArt Styles, color schemes. Icons & 3D Models: Insert → Icons (thousands of SVG icons, searchable, recolorable), Insert → 3D Models (rotate, resize). WordArt: decorative text — titles, logos, headers — Insert → WordArt, customize fill, outline, effects. Text Boxes: Insert → Text Box — independent text containers, position anywhere on page, link text boxes (overflow text flows from one to another — newsletter layouts). Screenshot: Insert → Screenshot — capture other open windows or Screen Clipping (select region). Alt Text: right-click image → Edit Alt Text — describe image for accessibility (screen readers), required for ADA/Section 508 compliance. Healthcare graphics: facility logos on letterheads, organizational charts (SmartArt hierarchy), process flowcharts for procedures (SmartArt process), Venn diagrams for concept overlap, clinical images in patient education materials, icons for visual wayfinding in documents
   - Cover: Text wrapping options comparison (In Line/Square/Tight/Behind/In Front), SmartArt category overview with examples, picture formatting toolbar, alt text accessibility requirement

### Unit 3: Advanced Document Features (L9-14)
9. **"Headers, Footers & Page Numbers"** — Headers and footers: text/images that appear at top/bottom of EVERY page (or section). Inserting: Insert → Header / Footer → choose design (Blank, Blank Three Columns, Austin, Banded, etc.), or double-click in header/footer area. Header & Footer tab: appears when editing header/footer — navigation (Go to Header/Footer, Previous/Next Section), options (Different First Page, Different Odd & Even Pages, Link to Previous — critical for multi-section documents), insert elements (Date & Time, Document Info — file name, file path, author, Page Number, Quick Parts/Fields). Page numbers: Insert → Page Number → Top/Bottom/Page Margins/Current Position, format (1,2,3 or i,ii,iii or A,B,C), start at (specify starting number — useful when front matter uses roman numerals and body restarts at 1). Different First Page: check in Header & Footer tab — cover page gets no header/footer (or different one), rest of document gets standard. Different Odd & Even: right-facing pages get one header (page number on right), left-facing pages get different header (page number on left) — for printed booklets. Section-specific headers: by default, sections are Linked to Previous — header from prior section carries forward. To create DIFFERENT headers per section: click into header → UNCHECK "Link to Previous" → edit independently. Example: cover page (no header) + table of contents (roman numerals, "Table of Contents" header) + body chapters (arabic numbers, chapter name header). Fields: Insert → Quick Parts → Field — dynamic content that updates automatically. Useful fields: DATE (current date), FILENAME (document file name), AUTHOR (creator), NUMPAGES (total page count), PAGE (current page), SECTIONPAGES (pages in current section), STYLEREF (pulls nearest heading text — auto-updating chapter titles in headers). Building blocks: save custom headers/footers as building blocks (Insert → Quick Parts → Save Selection to Quick Part Gallery) — reuse across documents. Healthcare headers/footers: facility name + logo in header, "CONFIDENTIAL" watermark, policy number + revision date in footer, "Page X of Y" for multi-page documents, "DRAFT" watermark during review, controlled document numbering
   - Cover: Header/Footer tab options diagram, section-specific header setup (Link to Previous toggle), page numbering restart between sections, field code examples

10. **"Table of Contents, Cover Pages & Navigation"** — Table of Contents (TOC): auto-generated from heading styles. Creating: References → Table of Contents → choose style (Automatic Table 1/2 — includes "Contents" title and auto-updates, Manual Table — type your own entries). How it works: Word scans for Heading 1/2/3 styles → creates hyperlinked entries with page numbers → tab leaders (dots) connect title to page number. Customizing: References → Table of Contents → Custom Table of Contents — show levels (how many heading levels to include), tab leader style (dots, dashes, solid line, none), formats (template styles), right-align page numbers. Updating TOC: right-click → Update Field → Update page numbers only (if only pages changed) or Update entire table (if headings added/removed/renamed). TOC fields: TOC is a FIELD — Ctrl+click to navigate to heading, gray shading shows it's a field, Alt+F9 toggles field code view. Table of Figures: References → Insert Table of Figures — auto-generated from Insert → Caption labels (Figure 1, Table 1, Equation 1). Cross-references: References → Cross-Reference — insert dynamic references to headings, figures, tables, footnotes, bookmarks, numbered items — updates automatically when content moves ("see Figure 3 on page 12" → page number auto-updates). Cover pages: Insert → Cover Page — pre-designed templates (Austin, Banded, Facet, Grid, Ion, Whisp), customizable — replace placeholder text, add/remove elements, or build custom from scratch. Bookmarks: Insert → Bookmark — name a location in document, navigate to it (Ctrl+G → Bookmark), use in cross-references, hyperlinks, and mail merge. Hyperlinks: Ctrl+K — link to web page, another file, place in this document (bookmark or heading), or email address. Navigation Pane: View → Navigation Pane — Headings tab (outline view, click to jump, drag to reorganize), Pages tab (thumbnails), Results tab (search). Document Map vs Navigation Pane: same concept, Navigation Pane is the modern version. Healthcare TOC: policy and procedure manuals (TOC with 3 heading levels), compliance manuals, employee handbooks, quality improvement reports, accreditation survey preparation binders — all require professional TOC
   - Cover: TOC creation from heading styles flowchart, TOC customization options, cross-reference types and use cases, cover page with TOC document structure

11. **"References: Footnotes, Endnotes & Citations"** — Footnotes: appear at bottom of the SAME PAGE — References → Insert Footnote (Ctrl+Alt+F). Used for: explanatory notes, additional context, source citations in some styles. Endnotes: appear at END OF DOCUMENT (or end of section) — References → Insert Endnote (Ctrl+Alt+D). Difference: footnotes = same page, endnotes = end of document. Customizing: References → Footnote launcher → number format (1,2,3 or i,ii,iii or symbols), start at, numbering (continuous, restart each section, restart each page), convert between footnotes and endnotes. Citations & Bibliography: References → Citations & Bibliography group. Citation style: APA 7th, MLA 9th, Chicago, Turabian, Harvard, IEEE, Vancouver, AMA — select from References → Style dropdown. Adding sources: References → Insert Citation → Add New Source — fill in fields (author, title, year, journal, volume, pages, URL, DOI), source type (book, journal article, website, conference proceedings, report). Source Manager: References → Manage Sources — master list (all sources ever created) vs current list (sources in this document), copy between lists, edit, delete. Insert citation: place cursor → References → Insert Citation → choose source — appears as (Author, Year) or [1] depending on style. Bibliography/Works Cited: References → Bibliography → insert pre-formatted bibliography that pulls from all citations in document — auto-formatted to selected style. Updating: add new citations → right-click bibliography → Update Field. Placeholder citations: insert citation without full source info → fill in later via Source Manager. Captions: References → Insert Caption — automatic numbering for figures, tables, equations — "Figure 1: Hospital Organization Chart". Cross-reference to captions: "As shown in Figure 3..." — auto-updates if figure numbers change. Healthcare references: research papers (APA style dominant in health sciences), policy documents citing regulations (42 CFR §482.24), quality reports citing accreditation standards, educational materials with source citations, capstone projects, RHIT exam study materials
   - Cover: Footnote vs endnote placement diagram, citation workflow (add source → insert citation → generate bibliography), citation style comparison (APA vs MLA vs AMA), caption and cross-reference relationship

12. **"Mail Merge: Personalized Mass Documents"** — What is mail merge: creating personalized copies of a document by combining a main document (template) with a data source (recipient list). Three components: Main Document (the letter/email/label template with merge fields), Data Source (list of recipients — Excel spreadsheet, Outlook contacts, Word table, Access database, CSV), Merged Document (personalized output — one copy per recipient). Mail merge types: Letters (personalized correspondence), Envelopes (addressed envelopes), Labels (mailing labels, name badges, file folder labels), Email Messages (personalized email campaigns), Directory (catalog/list — all records in one document). Step-by-Step Mail Merge Wizard: Mailings → Start Mail Merge → Step-by-Step Mail Merge Wizard — 6 steps: Select Document Type → Starting Document → Select Recipients → Write Letter → Preview Results → Complete Merge. Quick method: Mailings tab — Start Mail Merge (type) → Select Recipients (data source) → Insert Merge Field (place fields) → Preview Results → Finish & Merge. Data source: Use Existing List (Excel — BEST practice: clean data, one row per record, headers in row 1, no blank rows, no merged cells), Type a New List (Word creates table), Select from Outlook Contacts. Merge fields: «FirstName» «LastName» «Address» — Mailings → Insert Merge Field → select field from data source. Address Block: Mailings → Address Block — pre-formatted address field (Name + Address + City/State/ZIP — auto-formats based on country). Greeting Line: Mailings → Greeting Line — "Dear Mr. Smith:" with fallback for missing data. Rules (conditional content): Mailings → Rules — If...Then...Else (include different text based on field value — "If Gender = F, Dear Ms., If Gender = M, Dear Mr."), Skip Record If (exclude records meeting condition), Next Record, Merge Record #. Preview: Mailings → Preview Results — cycle through recipients, verify formatting, Find Recipient. Finishing: Mailings → Finish & Merge → Edit Individual Documents (creates one large document with all letters — review before printing), Print Documents (directly to printer), Send Email Messages (requires Outlook). Labels: Mailings → Labels — select label product (Avery 5160, 5163, etc.), merge fields onto label, update all labels. Healthcare mail merge: patient appointment reminders (Dear «PatientName», your appointment with Dr. «PhysicianName» on «Date»...), physician credentialing letters, insurance correspondence, HIPAA notice of privacy practices distribution, employee training notification letters, coding query letters, compliance audit notifications
   - Cover: Mail merge 3-component concept (document + data + output), merge field placement in letter, Rules If/Then/Else logic, label merge layout

13. **"Forms & Document Controls"** — Why forms in Word: create fillable documents — standardize data collection, protect format while allowing input, digital forms without specialized software. Developer tab: File → Options → Customize Ribbon → check Developer — exposes form controls. Content controls (modern, recommended): Rich Text (formatted text input), Plain Text (unformatted text), Picture (insert image), Check Box (yes/no checkboxes), Combo Box (type or select from list), Drop-Down List (select from predefined list only — best for standardized data), Date Picker (calendar selector), Building Block Gallery (insert building blocks), Repeating Section (add multiple instances of a group — multiple medications, multiple diagnoses). Content control properties: title (label shown above control), tag (identifier for programmatic use), placeholder text ("Click here to enter text..."), design (bounding box, start/end tag, or none), locking (content cannot be deleted, content cannot be edited), style to format contents. Legacy form fields: text box (with format — regular text, number, date, calculated), check box, dropdown — older method, still used for some purposes, requires form protection to function. Protecting forms: Developer → Restrict Editing → Allow only: Filling in forms — locks all document content EXCEPT form fields, users can only interact with form fields, optional password. Templates with forms: save as .dotx template — users open template to create new filled-in copy. Distributing: email as attachment, SharePoint, share via OneDrive. Printing forms: print blank (for hand-filling), print filled (for records), both are useful in healthcare transition from paper to digital. Healthcare forms: patient intake form (name, DOB, insurance — dropdowns for gender, state; date picker for DOB; checkboxes for conditions), consent forms (signature line, date picker, checkboxes for consent items), employee evaluation forms, incident report forms, coding audit worksheets, physician query templates (dropdown for query type, text fields for clinical details), ROI request forms
   - Cover: Content control types with examples, form protection settings, healthcare intake form mockup with controls labeled, template distribution workflow

14. **"Find & Replace Advanced, Special Characters & AutoFormat"** — Advanced Find & Replace (Ctrl+H → More >>): search options — match case, find whole words only, use wildcards, sounds like (English), find all word forms. Wildcard searches: ? (any single character — "b?t" finds bat, bet, bit, bot, but), * (any string of characters — "pre*" finds preview, predict, premium), [abc] (any one of these characters — "[aeiou]" finds vowels), [a-z] (range), [!abc] (NOT these characters), {n} (exactly n occurrences — "s{2}" finds "ss"), {n,m} (between n and m), @ (one or more of preceding — "lo@t" finds lot, loot). Find formatting: click in Find what → Format button → find all bold text, specific font, specific style, specific paragraph formatting — then replace with different formatting. Replace with nothing: find text → leave Replace with empty → Replace All = delete all instances. Special characters: Insert → Symbol → Special Characters tab — Em Dash (—, also Ctrl+Alt+minus on numpad), En Dash (–, Ctrl+minus on numpad), Non-Breaking Space (Ctrl+Shift+Space — keeps words together, prevents line break between them — "Dr. Smith" should use non-breaking space), Non-Breaking Hyphen (Ctrl+Shift+minus — prevents hyphenated words from splitting across lines), Optional Hyphen (Ctrl+minus — breaks word only if at end of line), Section Break, Page Break. In Find/Replace: ^p (paragraph mark), ^t (tab), ^l (manual line break), ^^ (caret), ^n (column break), ^s (non-breaking space), ^~ (non-breaking hyphen), ^m (manual page break), ^b (section break in Find), ^c (clipboard contents in Replace — paste clipboard into replace). AutoFormat: File → Options → Proofing → AutoCorrect Options → AutoFormat As You Type — "Straight quotes" to "smart quotes", ordinals (1st) to superscript, fractions (1/2) to ½, hyphens (--) to em dash (—), *bold* and _italic_, auto-bullet/numbered lists, auto-border (type === and Enter for border). AutoCorrect entries: add custom — type abbreviation, auto-replace with full text (e.g., "hx" → "history", "pt" → "patient" — but be careful with medical abbreviations that have multiple meanings). Healthcare Find/Replace: standardize terminology (find "pt" replace with "patient"), remove double spaces, find-and-format all ICD-10 codes in document (wildcard: "[A-Z][0-9][0-9].[0-9A-Z]"), clean up imported text from EHR
   - Cover: Wildcard syntax reference card, special character shortcuts, Find formatting workflow, AutoCorrect/AutoFormat settings

### Unit 4: Long Documents & Professional Output (L15-18)
15. **"Long Document Management"** — Master documents: View → Outline → Show Document → create structure of subdocuments — each chapter/section in separate file, master document assembles them. When to use: very long documents (200+ pages), multiple authors working on different sections, textbooks, policy manuals, annual reports. Subdocuments: inserted as links (expand/collapse), edit individually or within master, locked when another user has open. Document outline: View → Outline — promote/demote headings, move sections, collapse/expand levels, show first line only. Document properties: File → Info → Properties — title, author, subject, keywords, category, comments — searchable metadata, appears in file explorer details view. Go To: Ctrl+G or F5 — navigate by page, section, line, bookmark, comment, footnote, endnote, table, graphic, equation, heading. Word Count: Review → Word Count or Status Bar — pages, words, characters (with/without spaces), paragraphs, lines — useful for meeting length requirements. Document statistics: File → Info → Properties → Advanced Properties → Statistics — creation date, last modified, total editing time, revision number. Compare documents: Review → Compare — compare two versions, shows differences as tracked changes, useful for identifying what changed between drafts, legal document comparison. Combine documents: Review → Combine — merge changes from multiple reviewers into one document (each reviewer's changes shown in different color). Building Blocks Organizer: Insert → Quick Parts → Building Blocks Organizer — manage all building blocks (AutoText, headers, footers, cover pages, watermarks, equations, tables) in one place, edit, delete, change gallery/category. Quick Parts: Insert → Quick Parts — Document Property (insert fields that pull from document properties), Field (insert dynamic fields — date, page count, file name, author), AutoText (saved text snippets). Healthcare long documents: Joint Commission survey preparation binders (hundreds of pages), compliance manuals, employee policy handbooks, annual quality reports, HIM department procedure manuals, coding guidelines reference documents
   - Cover: Master document with subdocuments concept, Outline view with heading levels, Compare/Combine document workflow, building blocks gallery

16. **"Templates: Creation & Management"** — What is a template: a pre-designed document that serves as a starting point for new documents — contains formatting, styles, layout, boilerplate text, building blocks, macros. Template types: .dotx (standard template), .dotm (macro-enabled template), Normal.dotm (the default template — all new blank documents use it, stores default styles/AutoText/macros). Built-in templates: File → New → search (resume, letter, report, flyer, newsletter, invoice, calendar, APA paper) — thousands available from Microsoft. Creating from scratch: design document with all desired formatting/content → File → Save As → change file type to Word Template (.dotx) → saves to Custom Office Templates folder. Creating from existing document: open document → remove document-specific content, keep formatting/boilerplate → Save As template. Template components: styles (define formatting), themes (colors, fonts, effects), page layout (margins, orientation, sections), boilerplate text (standard paragraphs, legal language, headers), building blocks (custom headers/footers, cover pages, Quick Parts), content controls (form fields), macros (automation). Using templates: File → New → Personal (custom templates) → click template → creates new document based on template. Modifying Normal.dotm: changes affect ALL new blank documents — be careful. Access: usually at C:\Users\[username]\AppData\Roaming\Microsoft\Templates\Normal.dotm. Organizational templates: share via network drive, SharePoint, or group policy — standardize documents across department/facility. Template with content controls: create fillable template — users open, fill in fields, save as regular document. Themes: Design tab → Themes — change color palette, font set, and effects simultaneously. Custom themes: Design → Colors → Customize Colors (define 12 theme colors), Design → Fonts → Customize Fonts (heading + body font pair), save as custom theme. Healthcare templates: policy template (standard header with logo, revision history table, approval signatures, formatting styles), memo template, meeting minutes, patient letter template (with mail merge fields), incident report form, coding productivity report template, compliance audit checklist, committee charter template — consistency across facility documents
   - Cover: Template creation workflow, template components diagram, Normal.dotm location and purpose, healthcare template library examples

17. **"Review, Proofing & Accessibility"** — Spell check: Review → Spelling & Grammar (F7), or right-click wavy underlines (red = spelling, blue = grammar, purple = refinement suggestion). Custom dictionary: add medical terms that Word doesn't know (right-click → Add to Dictionary, or File → Options → Proofing → Custom Dictionaries). Medical spell-check: install medical dictionary add-in or build custom dictionary with medical terminology (ICD-10 terms, drug names, anatomical terms). Grammar check: File → Options → Proofing → Writing Style (Grammar & Refinements) — customize which rules to check (passive voice, sentence length, gender-neutral language, clichés, formality). Editor (M365): Review → Editor — AI-powered writing assistant, scores document on Clarity, Conciseness, Formality, Inclusiveness, Punctuation Conventions, Vocabulary. Thesaurus: Review → Thesaurus (Shift+F7) — synonyms and related words. Translate: Review → Translate — translate document or selected text (useful for multilingual patient communications). Read Aloud: Review → Read Aloud — hear document read aloud, catches errors you miss visually. Track Changes: Review → Track Changes (Ctrl+Shift+E) — records all edits: insertions (colored underline), deletions (colored strikethrough), formatting changes (noted in margin). Display options: All Markup (show changes inline), Simple Markup (clean view with red line in margin indicating changes), No Markup (preview final document), Original (see original before changes). Reviewing pane: Review → Reviewing Pane — list of all changes and comments in order. Comments: Review → New Comment (Ctrl+Alt+M) — threaded discussion in margin, @mention collaborators, mark as resolved. Accepting/Rejecting: Review → Accept/Reject — one at a time or all at once, Accept and Move to Next, Accept All Changes in Document. Restrict Editing: Review → Restrict Editing — formatting restrictions (only allow specific styles), editing restrictions (no changes, tracked changes only, comments only, filling in forms only), enforce with password. Accessibility Checker: Review → Check Accessibility — identifies issues: missing alt text, poor color contrast, missing table headers, non-descriptive hyperlinks, use of blank characters for spacing. Accessibility fixes: add alt text to all images, use proper heading styles (not just bold/large text), add table header rows, use descriptive hyperlink text ("Click here" → "View the HIPAA policy"), avoid relying solely on color to convey information. Inspector: File → Info → Check for Issues → Inspect Document — find and remove: comments, tracked changes, hidden properties/personal information, invisible content, hidden text — CRITICAL before sharing healthcare documents externally (remove PHI metadata). Healthcare review: policy review cycle (draft → department review with Track Changes → committee approval → final), multiple reviewer workflow (combine changes from medical staff, legal, compliance), accessibility compliance for patient-facing documents (ADA, Section 508), document inspection before public release
   - Cover: Track Changes display modes comparison, comment threading and resolution, accessibility checker issue types, document inspection checklist

18. **"Printing, PDF & Professional Output"** — Print settings: Ctrl+P — Print Preview shows exactly what will print. Settings: printer selection, page range (all, current page, custom range — "1-5, 8, 12-15", selection), one-sided vs two-sided (duplex — flip on long edge for portrait, short edge for landscape), collated vs uncollated, orientation override, paper size, margins (per-page adjustment), pages per sheet (1, 2, 4, 6, 8, 16 pages per physical page — for draft review). Print Preview navigation: arrow buttons to browse pages, verify headers/footers, check page breaks, zoom to actual size. Scaling: custom percentage or fit to page. Printing specific elements: File → Print → Settings → Print All Pages dropdown → Print Markup (include tracked changes), Document Properties (print metadata), Styles (print style definitions), Building Blocks. PDF creation: File → Save As → PDF (full fidelity, preserves formatting across all systems), File → Export → Create PDF/XPS — options: optimize for standard (printing) or minimum size (online), publish what: document, bookmarks (from headings), hyperlinks, accessibility tags. PDF options: create bookmarks from headings (auto-generates PDF navigation from Word heading styles — essential for long documents), document properties, bitmap text for complex formatting. Print to PDF: Ctrl+P → printer → Microsoft Print to PDF — quick method for single-use. Envelope printing: Mailings → Envelopes — select envelope size (#10 standard business, #9, A2, etc.), delivery/return address, print single or add to document. Label printing: Mailings → Labels — select label product (Avery, etc.), full page of same label or single label. Page borders: Design → Page Borders — art borders, line borders, shadow/box/3D, apply to whole document or specific sections (for certificates, formal documents). Watermarks: Design → Watermark — predefined (CONFIDENTIAL, DO NOT COPY, DRAFT, URGENT) or custom text/image. Healthcare output: policies printed double-sided for binders, patient education single-sided with large font, PDF for electronic distribution (most common in modern healthcare), CONFIDENTIAL watermark on sensitive documents, controlled document printing (limited copies, numbered), labels for chart folders, envelopes for patient correspondence, accessible PDF for public-facing documents
   - Cover: Print settings dialog walkthrough, PDF creation options, envelope/label setup, watermark and page border applications

### Unit 5: Collaboration & Automation (L19-21)
19. **"Co-Authoring & Cloud Collaboration"** — OneDrive & SharePoint: cloud storage for M365 documents, required for co-authoring and AutoSave. Saving to cloud: File → Save As → OneDrive (personal) or SharePoint/Teams (organizational), or AutoSave toggle (top-left, automatically saves every few seconds to cloud). Sharing: File → Share → invite people (enter email, set permissions: Can Edit vs Can View), get link (Anyone, People in your organization, Specific people — with Edit or View permission), send as attachment (Word or PDF). Co-authoring: multiple people editing SAME document simultaneously (requires cloud save). How it works: colored cursors show where others are editing, changes sync in near-real-time, AutoSave must be enabled. Version History: File → Info → Version History — see all auto-saved versions, open/restore previous versions, compare versions. Comments for collaboration: @mention specific people in comments → they receive email notification, threaded replies, resolve when addressed, filter comments by reviewer. Track Changes in collaboration: share document → reviewer enables Track Changes → edits are tracked → author reviews/accepts/rejects. Simultaneous vs sequential review: co-authoring = simultaneous (best for brainstorming, real-time meetings), Track Changes = sequential (best for formal review — one reviewer at a time, or combine multiple). Microsoft Teams integration: attach Word document in Teams channel → Edit in Teams (browser version) or Edit in Desktop App, conversations in Teams thread linked to document. SharePoint document libraries: central storage for department documents, check in/check out (prevent simultaneous conflicting edits when Track Changes preferred over co-authoring), metadata columns (document type, department, status, owner, review date), versioning (major/minor versions), content approval workflows, document IDs. Compare/Combine for offline review: reviewer works on local copy → author uses Review → Compare to see differences → accept changes. Healthcare collaboration: policy development (draft → multi-department review → legal review → committee approval → CEO sign-off), joint commission prep documents (multiple departments contributing sections), quality improvement reports (data analysts + clinical staff + administration), accreditation survey preparation (facility-wide collaboration on documentation), HIPAA considerations (cloud storage requires BAA with Microsoft, control sharing permissions carefully, avoid patient-specific data in document titles/properties)
   - Cover: Co-authoring real-time editing concept, sharing permissions matrix, version history timeline, SharePoint document library features

20. **"Automation: Macros, Quick Parts & Advanced Features"** — Macros in Word: automate repetitive tasks. Recording: View → Macros → Record Macro (or Developer → Record Macro), name, assign to button or keyboard shortcut, perform actions, stop recording. Running: View → Macros → View Macros → Run, or assigned shortcut/button. Example macros: format policy header (apply consistent Title style, insert logo, set margins), insert standard disclaimer paragraph, format selected text as procedure step, clean up imported text (remove extra line breaks, standardize spacing). Macro security: File → Options → Trust Center → Macro Settings — disable all (safest), disable with notification (recommended), enable all (dangerous). Quick Parts & Building Blocks: AutoText (Insert → Quick Parts → AutoText — save and reuse frequently typed text with F3 shortcut, e.g., type "discl" + F3 → inserts full disclaimer paragraph), Document Property Quick Parts (insert Author, Company, Title fields that auto-populate from properties), custom building blocks (save any content — formatted text, tables, images — to Quick Parts gallery, organize by gallery/category). Fields: Insert → Quick Parts → Field — dynamic content: DATE (auto-updating date — format options), CREATEDATE (document creation date, fixed), PRINTDATE (when last printed), FILENAME (document file name), FILESIZE, IF (conditional field — IF merge field = value THEN text ELSE text), SEQ (auto-numbering — figure numbers, step numbers, independent sequences), DOCPROPERTY (insert any document property), NUMWORDS, NUMPAGES. Field codes: Alt+F9 toggles between field results and field codes, Ctrl+A then F9 updates all fields in document, right-click field → Update Field. Linked content: Paste Special → Paste Link — linked Excel chart/table in Word document updates when source Excel file changes (Edit → Links → Update Now, or auto-update on open). OLE (Object Linking and Embedding): Insert → Object — embed Excel spreadsheet, Visio diagram, equation editor, or link to external file. Healthcare automation: standard policy formatting macro (apply styles, insert standard sections, set up header/footer), auto-insert HIPAA disclaimer, generate monthly report template with auto-date fields, linked Excel quality dashboard chart in Word quality report (chart updates when Excel data refreshes)
   - Cover: Macro recording and running workflow, Quick Parts/Building Blocks organization, field code examples, linked Excel content concept

21. **"Word for Healthcare Document Creation"** — Applying all skills to create real healthcare documents. Policy & Procedure document: structure (policy number, effective date, revision date, approval signatures, purpose, scope, definitions, policy statement, procedure steps, references, attachments), formatting (heading styles linked to multilevel numbering, hanging indents for procedure steps, tables for revision history and approval, borders/shading for warnings), distribution (PDF for electronic, controlled print copies, SharePoint document library with version control). Patient correspondence letter: letterhead template (logo, facility name/address, phone/fax), merge fields for personalization (patient name, address, physician name, appointment date), professional formatting (block style, proper date/salutation/closing). Committee meeting minutes: template with header (committee name, date, time, location), attendee table, agenda items with discussion/action items, motions/votes, next meeting date. Healthcare report: quality improvement report — title page (custom cover page), executive summary, table of contents (auto-generated from headings), data tables (imported from Excel or formatted in Word), charts (linked from Excel), findings and recommendations, appendices, citations (APA style), page numbers (roman numerals front matter, arabic body). Employee handbook section: consistent styles, hyperlinked TOC, index, controlled formatting with restricted editing, accessibility compliant. Coding query document: form template with content controls — dropdown for query type (clinical clarification, specificity, conflicting documentation), text fields for clinical indicators, date picker, physician response area. Best practices synthesis: style consistency, template usage, proper heading structure, accessibility, document inspection before sharing, HIPAA compliance in document creation, version control, professional appearance
   - Cover: Policy document structure diagram, patient letter template layout, committee minutes template, quality report document architecture
